## What landed in adapters.py
1. **`cinematic_prompt(brief, palette, kind)`** — builds the production prompt:
   - `_CINE_SCAFFOLD` (fixed cinematography string: "cinematic product still,
     50mm f1.8, shallow depth of field, soft cool key + brand-accent rim light,
     premium dark studio, … glossy reflection, centered, Apple-keynote look") —
     present in BOTH kinds.
   - **kind="hero"** (literal-UI/dashboard plates): brief + scaffolding ONLY.
     NO brand-hex, NO anti-text (videotape-alpha renders UI text legibly; a hero
     plate wants it readable). → winner = evidence/prompt-ab/b-cinematography.png
   - **kind="establish"** (abstract/establishing): scaffolding + **brand-accent
     hex injection** (accent/accent2 from `palette`) + **anti-text guard**
     (`_ANTI_TEXT`: "all interface text illegible — only soft blurred light
     shapes and bokeh; no readable words, no wordmarks, no watermarks") +
     **negative-space-for-title** note (`_TITLE_ROOM`). Any unknown kind falls to
     this (safer) track. → winner = evidence/prompt-ab/e-fullformula.png
   - Brief preserved verbatim at the front; always returns one well-formed
     period-terminated string; empty brief / accentless palette handled.
   - **Model-robust:** general cinematography + brand-hex + CONDITIONAL anti-text.
     No videotape-alpha-specific hacks; the same tokens carry to Seedance/Ultra.
2. **`detect_kind(scene)`** — classifies a scene into "hero" / "establish":
   - explicit `scene["kind"]`/`scene["plate"]` wins;
   - else text hints in id+brief (`_HERO_HINTS` vs `_ESTABLISH_HINTS`);
   - mixed hints → still model (gpt_image_2)=hero, video model=establish;
   - no hint → gpt_image_2=hero, else establish (sensible default).
3. **Wiring in `_generate_cinematic_real`** (the deliverable point): replaced the
   verbatim `prompt = scene.get("brief")` with
   `brief = scene.get("brief")`; `kind = detect_kind(scene)`;
   `palette = remotion_codegen.palette_for(company_url or scene.get("company_url"))`;
   `prompt = cinematic_prompt(brief, palette, kind)`.
   - Clean wiring chosen: added an optional `company_url=None` kwarg to
     `generate_cinematic` → `_generate_cinematic_real` (defaulted, so the
     orchestrator's existing `generate_cinematic(scene, out, mode)` call sites
     keep working untouched). The palette is resolved INSIDE adapters via
     `remotion_codegen.palette_for(...)`, falling back to `scene["company_url"]`.
   - NEXT-ITER NOTE: the company_url currently lives on `job["company_url"]`
     (scenes carry `company_url: null` in plan.json). The kwarg is ready; when the
     real-Seedance iteration runs, pass `company_url=job.get("company_url")` at
     orchestrator.py:288 & :317 so establishing plates get the right brand hexes.
     Until then `palette_for(None)` returns the `_default` palette (still valid).
