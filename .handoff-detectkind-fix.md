# Handoff — detect_kind anti-text guard for ALL video ($0, NO real gen)

## Why
The Seedance VIDEO A/B (`.handoff-seedance-ab.md`) proved video garbles literal UI
text under motion regardless of hero/dashboard hints. But `detect_kind` could still
return "hero" (the no-anti-text track) for a VIDEO scene carrying a "hero"/"dashboard"/
"ui" hint — the exact case that garbled. Anti-text legibility is a still-only property
of the gpt_image_2 / videotape-alpha path.

## The one-line logic change (adapters.py, detect_kind ONLY)
Added a HARD OVERRIDE at the very top of the heuristic body — before the explicit
kind/plate check, so it catches EVERY path:

    model = (scene.get("model") or "").lower()
    if model != "gpt_image_2":
        return "establish"

Any model that isn't the gpt_image_2 still is a video model → forced to the anti-text
"establish" track. The "hero" (literal-UI, no-anti-text) track is now reachable ONLY
when model == "gpt_image_2".

Because every path below the guard now has model == "gpt_image_2", the now-dead
duplicate `model = ...` reassignment and the `model == "gpt_image_2"` branches were
collapsed (behavior for the still is byte-for-byte identical: establish iff a pure
establish hint with no hero hint, else hero). No other function touched.
