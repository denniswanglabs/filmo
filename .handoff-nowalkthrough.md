# Handoff: remove walkthrough at the planner level

Date: 2026-06-21
Goal: "Get rid of the walkthrough for now." Make the agent STOP planning + producing
the product-walkthrough scene by killing it at the PLANNER level so a walkthrough
simply never gets planned. Orchestrator/adapters walkthrough PRODUCE-code left DORMANT
(untouched) — it just won't be invoked because nothing plans a walkthrough.

## Key discovery
The Nemotron-guided planner's ACTUAL instructions are NOT in `planner-prompt.md`
(that file is documentation). They live in `validate_planner.py`'s `SYSTEM_PROMPT`,
which `plan_job._plan_with_nemotron` imports as `vp.SYSTEM_PROMPT` and sends to the
model. So `validate_planner.py` had to be edited too (it is not in the DO-NOT-EDIT
list). Its `schema_check` is the planner's OWN self-test and was updated accordingly.

## Files changed
1. `plan_job.py`
   - Deterministic fallback (`_template_plan`): removed the hardcoded walkthrough
     scene + beat in ALL three styles (standard / snappy / cinematic). Replaced with
     non-walkthrough beats keeping the same durations so totals still sum to target:
       - standard : walkthrough -> `cine-feature` (cinematic, seedance_2_0, dur `feat`)
       - snappy   : walkthrough -> `feature-beat` (motion_graphic)
       - cinematic: walkthrough -> `cine-feature` (cinematic, seedance_2_0)
   - Renamed local `walk` -> `feat` (the middle content beat).
   - Removed "Keep the walkthrough tight" line from the SNAPPY `_STYLE_PROMPT`.
   - Updated a stale `_restyle_durations` comment (no walkthrough; 2-4 cinematic).
2. `validate_planner.py` (Nemotron-guided path + planner self-test)
   - `SYSTEM_PROMPT`: enum is now `title|cinematic|motion_graphic` (NO walkthrough);
     structure rule 3 now FORBIDS any walkthrough/screen-recording/product-tour scene;
     cinematic widened to 2-4; removed walkthrough from MODEL/VOICEOVER rules.
   - `schema_check`: now asserts walkthrough count == 0 (was == 1); cinematic 2-4
     (was 2-3); `allowed_types` drops walkthrough; model-null type set drops walkthrough.
   - `BRIEF.goal`: "...walkthrough of how to find your API keys" -> "30-second brand promo".
3. `planner-prompt.md` (documentation kept in sync with the live prompt)
   - enum, structure rules, model rules, voiceover rules, prose summary, and the
     harness post-parse assertion all updated to forbid walkthrough; cinematic 2-4.
4. `dashboard/serve.py`  (the running :3030 server's source; brief explicitly named it)
   - `_api_build` default goal: "30-second promo plus a short product walkthrough"
     -> "30-second brand promo". Backup: `dashboard/serve.py.pre-nowalk.bak`.
   - `/api/analytics` route left intact. No other routes touched.

## NOT touched (other agents own these; dormant walkthrough produce-code stays)
plan_schema.py, orchestrator.py, adapters.py, pricing.*, producer.py, dashboard/* (UI),
run_all_tests.sh, and ALL of tests/ (the walkthrough tests there exercise the dormant
produce-path / orchestrator / adapters, not the planner). No dedicated test_plan_job.py
or test_validate_planner.py exists; the planner's only self-test is schema_check, updated.

durations sum to 30.
  standard : title, cinematic, cinematic, cinematic, title       (3+6+10+6+5=30)
  snappy   : title, cinematic, motion_graphic, cinematic, motion_graphic, cinematic, title (=30)
  cinematic: title, cinematic, cinematic, title                  (2+13+13+2=30)
validate_planner.schema_check on fallback plan: PASS.
schema_check now REJECTS any plan that contains a walkthrough scene.
vp.SYSTEM_PROMPT (sent to Nemotron) contains the "NEVER include a walkthrough" rule
and no longer lists walkthrough as an allowed type.
py_compile OK on plan_job.py, validate_planner.py, dashboard/serve.py.
