## EVAL DISCIPLINE (iterate without fooling yourself)
- **ONE change per round, measured.** Change ONE lever → regenerate the SAME fixed subset → re-score vs OPTIMIZATION-SPEC.md → KEEP if mean improves, REVERT if it regresses or is flat. Never batch changes (you won't know what worked). [Hard lesson: batched explainer-agent changes dropped an eval 81%→62%.]
- **TWO INDEPENDENT TRACKS** (Dennis: "do both independently"):
  - **TRACK A — Dim-3 copy grounding** (prompt files only): `validate_planner.SYSTEM_PROMPT`, `_QUALITY_PROMPT`, `planner-prompt.md`, `plan_job` template beats. Fixes: let the planner use WORLD KNOWLEDGE of recognizable brands when scraped facts are thin; ban "describe-the-animation" copy; demand concrete real feature names + specific real-looking numbers + imperative couplets (per the reference template).
  - **TRACK B — Dim-5 real imagery** (capture/render files only): `capture_screenshots.py`, `adapters.generate_screenshots`, `studio/.../AppleScreenshot.tsx`, `style_fill` screenshot wiring. Screenshots are $0 (Playwright, no NIM). Fixes: capture the EMPHASIZED feature's page (not just homepage), capture 2-3 KEY pages, better framing/crop/zoom on the product UI, richer card composition. (Stretch: use walk-agent per-step captures for in-product imagery — that costs NIM, do sparingly.)
  - The two tracks touch DISJOINT files → can run in parallel; each measures its own change.
- **Measure contribution, not coincidence** — confirm a change actually fired and helped before crediting it.
- **Fixed eval subset** for comparability: stripe, tripadvisor.com.tw, linear, shopify, plaid. Expand the roster only to TEST generality, never mid-comparison.
- **Always keep the build green** — after any source edit, run `./run_all_tests.sh --no-eval`; a broken build = auto-revert that change.
- **CONVERGENCE / STOP:** subset mean ≥4.3 AND no dim <4 → expand roster to the full 12; if the wider roster also converges → "not iterable anymore" = DONE, write the final report. Stop a single track after 3 straight rounds with <0.1 mean gain (lever tapped) and move to the next-weakest dim.
