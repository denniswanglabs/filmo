## Word->beat mapping (drift handling)
1. `build_word_index(beats)` concatenates beat texts, records the cumulative
   word-index range each scene owns (parallel `owners`/`script_tokens` arrays).
2. `map_words_to_beats` is a monotonic two-pointer SEQUENCE align (NOT exact
   string match -- whisper mishears 'Stripe'->'Strike'). On a normalized match
   within a 4-token lookahead it consumes that script token; on NO match the
   hypothesis word is a split/insertion/mishear and inherits the CURRENT owner
   WITHOUT consuming a token (so an extra word like 'check'+'out' can't push the
   cursor past a beat boundary). Cursor clamps to the last token's owner.
