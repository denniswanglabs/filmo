## Root Cause

**File:** `/Users/dennis/Desktop/Projects/Hackathons/hermes-video-agent/style_fill.py`  
**Line 160 (before fix):**
```python
"kicker": d.get("kicker") or brand.get("wordmark", "").upper(),
```

The `brand_theme.json` generated by `brand_extract.py` uses the key `"name"` (not `"wordmark"`) for the brand display name. So `brand.get("wordmark", "")` returned `""`, and the kicker was always empty for brands from this pipeline.

The theme block at line 440 already handles this correctly:
```python
theme["wordmark"] = brand.get("wordmark") or brand.get("brand") or brand.get("name") or ""
```

But `_shape_hero` at line 160 did not use the same full fallback chain.

**Secondary issue (visual only, not a bug):** The plan.json was generated with `"name": "Tripadvisor"` correctly but the plan's `brief` and VO script say "Com" throughout (the LLM used "Com" as a placeholder). This is an upstream plan_job.py issue — not fixed here.

---

## Fix Applied

**File:** `style_fill.py` line 160  

**Before:**
```python
"kicker": d.get("kicker") or brand.get("wordmark", "").upper(),
```

**After:**
```python
"kicker": d.get("kicker") or (brand.get("wordmark") or brand.get("brand") or brand.get("name") or "").upper(),
```

Syntax verified: `python3 -c "import ast; ast.parse(...)"` passes.  
Logic verified: With Tripadvisor brand_theme.json, the fix produces `'TRIPADVISOR'` as the kicker.
