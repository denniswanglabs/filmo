# Handoff — build_timeline.py (Phase 1, module 2: invert the duration lock)

## Goal
Kill the VO/visual mismatch at its root. The bug (plan_job.py:117 /
`_restyle_durations`): scene durations are locked BEFORE the VO exists, then the
voice is squeezed into fixed slots. This module inverts it: the word-aligned
voiceover OWNS the timeline; each scene's in/out comes from the span of words
spoken over it. `duration_s` is demoted to advisory/pricing-only.

## Delivered
- `build_timeline.py` (new, ~230 lines). CLI:
  `python3 build_timeline.py --scenes-file scenes.json
   --alignment runs/<id>/vo_alignment.json --fps 30 --out runs/<id>/timeline.json`

## Inputs / contract
- scenes.json: `[{id, archetype, duration_s? (ADVISORY), cues?:[{label, word}|{label, word_index}]}]`
- vo_alignment.json (from align_vo.py): `{audio_path, lang, total_duration_s,
  words:[{word,start_s,end_s,beat_scene_id}], beats:[{scene_id,start_s,end_s,text}]}`

## Output schema (EXACT)
```
{fps, total_frames, audio_path, lang,
 scenes:[{id, archetype, in_frame, out_frame,
          cues:[{label, word, at_frame}]}]}
```

## Rules implemented
1. Voiced scene: length from its word span (beats[] boundaries preferred, else
   union of words with beat_scene_id==id). `span_frames = round(end*fps) -
   round(start*fps)`. duration_s NEVER used here (that is the bug).
2. Unvoiced scene (no beat/words, e.g. logo hold): advisory hold from duration_s
   (fallback DEFAULT_HOLD_S = 1.5s). Slid in: in_frame = prev out_frame.
3. SLIDE/CONTIGUITY: every kept scene in_frame == previous out_frame; first at 0.
   No gaps, no overlaps, regardless of absolute beat drift.
4. Cut scenes: skipped via `_is_cut` (truthy `cut`/`declined`/`removed`, or
   `status` in {cut,declined,removed,dropped}). The rest slide earlier (no dead air).
5. Cues: resolve by `word` (case/punct-insensitive, first match in the scene's
   owned words) or `word_index` (into the scene's words). at_frame =
   round(word.start*fps), rebased by the scene's slide offset and clamped inside
   [in_frame, out_frame]. Unresolvable cues dropped.
6. total_frames = round(total_duration_s*fps). Last scene out_frame CLAMPED to
   total_frames (no silent tail / no overrun). Edge guard: if audio is shorter
   than the laid-out picture, total_frames bumped to last in_frame + 1.
