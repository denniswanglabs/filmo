# Handoff — quality-aware PLANNER (STANDARD = Remotion-only scenes)

Owner: quality-planner subagent, 2026-06-21.

## Goal / bug fixed
`selection.quality` already gated PRODUCE, but the PLAN didn't match: a STANDARD
shot list still showed Seedance / GPT-image cinematic scenes. Now the planner is
quality-aware at PLAN time:
- STANDARD => plan ONLY `title` + `motion_graphic` (Remotion-renderable). NO
  cinematic (no seedance_2_0 / gpt_image_2), NO walkthrough.
- PREMIUM => cinematic establishing/hero shots allowed (today's behavior).

## How quality threads to the planner
build_runner.run already received `--quality` and normalized it. Previously quality
was only stamped onto `plan["selection"]` AFTER planning. Now:
- `build_runner.py` (line ~106): `plan_job.plan_job(url, goal, dur, style=style, quality=quality)`
  — quality reaches the planner BEFORE scene types are chosen. `plan["selection"]`
  stamp is unchanged (still drives pricing/produce).
- `plan_job.plan_job(...)` gained a `quality` kwarg (default "standard"), normalized
  via `_normalize_quality`, threaded into BOTH `_plan_with_nemotron` and `_template_plan`.

## STANDARD = Remotion-only, enforced in BOTH paths
1. Nemotron path: `_QUALITY_PROMPT["standard"]` is appended to the SYSTEM_PROMPT
   AFTER the style block (so it overrides any cinematic-style text). It tells the
   model to use ONLY title + motion_graphic, no cinematic, no seedance/gpt models.
   `validate_planner.SYSTEM_PROMPT` itself now carries a QUALITY section + premium-only
   markers on the structure rules.
2. Deterministic fallback: `_template_plan` branches to `_standard_template_plan`
   when quality==standard => title-open + 3 motion_graphic feature beats + title-close,
   all model=null, durations summed to target. PREMIUM keeps the existing cinematic
   template per style.
3. Defense-in-depth: `_enforce_quality(plan, "standard")` runs after planning and
   coerces any stray cinematic/walkthrough scene to motion_graphic (model=null),
   preserving ids/order/durations/beats. Guarantees the rule even if Nemotron drifts.
4. `validate_planner.schema_check(plan, dur, quality=...)`: quality="standard"
   asserts ZERO cinematic + >=1 motion_graphic (walkthrough already asserted 0);
   quality="premium" (DEFAULT) keeps the 2-4 cinematic check. main() unchanged (defaults
   premium => live NVIDIA validation behavior preserved).

## Proof ($0, NVIDIA_API_KEY unset -> deterministic fallback)
- STANDARD (styles standard/snappy/cinematic): scenes = title + 3 motion_graphic +
  title; 0 cinematic, 0 walkthrough, no seedance/gpt models; sum==30; passes
  plan_schema.validate_plan AND schema_check(quality=standard).
- PREMIUM (standard/cinematic): 2-3 cinematic allowed; sum==30; passes validate_plan
  AND schema_check(quality=premium).
- Cross-check: a STANDARD plan FAILS schema_check(quality=premium) ("cinematic count=0").
- Backstop: a dirty plan with cinematic+walkthrough is coerced to title/motion_graphic.
- CLI: `plan_job.py --quality standard` => all model=None; `--quality premium` =>
  cinematic w/ seedance/gpt models.
