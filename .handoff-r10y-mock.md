## Problem (before)
3 bot-walled brands (shopify, tripadvisor.com.tw, huckberry) fell to an EMPTY
GREEN skeleton mock: sparse empty outline bars, generic `#7CFFB2` tint for
EVERY brand. Root cause: `_brand_accent_for_url` called `palette_for(url)`,
which NEVER returns empty for unknown brands — it returns the `_default`
palette whose accent is the green `#7CFFB2`. So the curated fallback map was
dead code and huckberry got green, not rust. The mock also had only 2 empty
tiles / 3 empty rows → read as a broken loading skeleton (D5=2).

## Fix (after) — all in adapters.py
1. **Real accent threading.** New `_accent_from_brand_theme(run_dir)` reads the
   canonical `runs/<id>/brand_theme.json` → `palette.accent` (the SAME accent the
   rest of the video uses). `_brand_accent_for_url(url, run_dir)` priority:
   (1) run-local brand_theme accent → (2) curated 12-brand map (huckberry rust
   `#BE512D`, shopify `#96BF48`, tripadvisor `#34E0A1`, …) → (3) palette_for ONLY
   when it matched a REAL brand entry (skips `_default` green) → (4) generic blue.
   `run_dir` derived from `out_path` (`<run_dir>/screenshots/shot-NN.png`), so the
   existing `generate_screenshots(url, shots_dir, ...)` caller is UNCHANGED.
2. **Populated, genre-aware surface (Pillow, real text).** New
   `_brand_mock_png_pil` draws a header bar with the REAL wordmark + nav, then a
   genre scaffold: e-commerce (shopify/huckberry/allbirds) → product GRID (8
   filled card tiles w/ labels + PRICE chips $148/$98/…); travel
   (tripadvisor/airbnb) → review FEED (ranked rows w/ RATING badges 4.8/4.6 +
   review counts); media (theverge) + saas (default) variants too. Slot 0 =
   catalog/grid, slot 1 = ranked detail rows — structurally distinct.
3. **ffmpeg fallback hardened** (`_brand_mock_png_ffmpeg`): if Pillow ever fails,
   still renders the REAL accent + a denser 8-tile product grid (text-free).
   Never the green default, never empty 2-tile skeleton.
