## The FLAG
`orchestrator.premium_menu_enabled()` — truthy `WS_PREMIUM_MENU` in
(`1`/`true`/`yes`/`on`, case-insensitive). Mirrors `producer._premium_menu_enabled`.
OFF -> no `premium` ledger block, no watermark, no format pack, no VO-engine
override; the STITCHED event string + stitch record shape are the exact pre-premium
ones.

## How `selection` threads through
1. `orchestrate()` calls `estimate(plan_path)` -> `producer.cmd_estimate`. With the
   flag ON the subprocess inherits the env, so `est` already carries
   `selection` + `menu` (Contracts 3 & 4) and `production_budget_cents` /
   `suggested_price_cents` are the MENU totals.
2. Right after the PRICE step (still before any money path), the orchestrator reads
   `selection = est["selection"]` (fallback: plan's selection / `pricing.default_selection()`),
   `menu = est["menu"]`, `boosters = set(selection["boosters"])`, and seeds
   `led.data["premium"]` (tier, boosters, options, watermark, rush, menu, line_items).
3. The boosters then drive produce behavior at their natural points in the loop.
   The locked `budget`/`price` are NOT recomputed here — they came from the menu.

## Each booster's PRODUCE behavior + where it lives
- **no_watermark** (`adapters.stitch(..., watermark=)`): watermark is ON iff
  `tier defaults.watermark` (only starter) AND `no_watermark` NOT bought. The mark
  is a drawn corner badge via `drawbox` (this ffmpeg has no drawtext/libfreetype):
  a brand-tinted bar + a lime inset stripe bottom-right, burned during the concat
  pass. `stitch` returns `watermark: True` ONLY when on (key omitted otherwise ->
  byte-identical OFF record).
- **multi_format** (`adapters.make_format_pack(final, run_dir, n, vo_path)`): after
  the main 16:9 stitch, produces N REAL cuts (N = `options.formats`) from
  `_FORMAT_PACK` in order: `9:16`, `1:1` (reframe = scale-cover + center-crop, no
  distortion), then `6s`/`15s`/`30s` (trim via `-t`, clamped to source length).
  Files land in `runs/<id>/formats/final_<label>.mp4`, audio copied when present.
  Per-cut failure is isolated -> a clearly-labelled dark-red `synth_clip` stub +
  `.STUB.txt` sidecar, `real:false`, pack continues. Recorded at
  `led.data["premium"]["format_pack"]`.
- **founder_voice** (orchestrator VO section): VO engine select edge(free) vs
  ElevenLabs(real). Real clone fires ONLY when `mode==real` AND consent
  RE-VALIDATED (see gate below). In mock (the $0 default) it ALWAYS uses edge and
  logs "mode=mock (no real clone)". Recorded at
  `led.data["voiceover"]["founder_voice"] = {requested, engine, consent_ok, owner, reason}`.
- **rush** (orchestrator PRICE section): price-only flag in mock — no wall-time
  change. `led.data["premium"]["rush"]=True` + a ledger event + the priced
  `Rush delivery` line item (price 5000c, cogs 0).

## Produce-layer consent gate (defense in depth)
`pricing.price_selection` refuses founder_voice without valid consent at PRICING
time (so `estimate` raises before produce — the primary gate). The orchestrator
ADDITIONALLY calls `pricing.validate_consent(selection)` inside the VO section
before any clone: if refused -> NO real call, force edge, log the refusal; if ok
but mock -> edge; only `ok AND mode==real` -> ElevenLabs. Test
`TestProduceLayerConsentGate` bypasses the pricing-time refusal (stubs
`orchestrator.estimate` to graft a refused selection onto a baseline est) and
monkeypatches `adapters._vo_elevenlabs` to a tripwire, proving the produce-layer
gate alone refuses the clone and never calls ElevenLabs.

## Ledger line-item shape (matches price_selection)
`led.data["premium"]["ledger"]`:
```
{ "line_items": [ {key,label,qty,price_cents,cogs_cents,margin}, ... ],
  "total_price_cents", "total_cogs_cents", "margin" }
```
Built from `menu.line_items` so labels + per-line + totals EQUAL
`pricing.price_selection(selection)` exactly (asserted in
`TestLedgerMatchesPriceSelection`) — the on-screen P&L and the produced ledger
cannot drift. Per-line `margin = (price-cogs)/price` (1.0 for 0-cogs lines).
Totals == the locked budget COGS + the customer price.
