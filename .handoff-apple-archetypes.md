## Cue-frame contract (SAME mechanism as the existing archetypes)
Each archetype is a <Sequence> child, so useCurrentFrame() is scene-LOCAL.
Timeline.tsx rebases build_timeline.py's absolute cue frames to scene-relative
(rebaseCues) before passing `cues` to the archetype. Each archetype looks up
cue frames by label via cueAt(cues,label,fallback) and fires reveals there.

Cue labels each archetype reads:
- apple-hero:      kicker-in, title-in, punch, product-in, subtitle-in
- apple-registry:  heading-in, pill, card-1..card-6
- apple-statement: line-1..line-N, footnote-in

## Motion (Apple iOS curves, NOT springs)
Added to motion.ts (non-breaking, append-only):
- EASE_OUT_QUART / EASE_IN_OUT_CUBIC  (Remotion Easing.bezier)
- easeOutCubic(t) = 1-(1-t)^3          (the screenshot-shrink curve, no overshoot)
- appleRise(frame,at,dy,dur)           (fade+slide-up, ease-out-quart)
- appleMaskRise(frame,at,dy,dur)       (slide-up title w/ clip mask)
- breathDrift(frame,settle,amp,period) (the tiny settled oscillation)
Honors feedback_apple_screenshot_animation: arrivals = cubic ease-out, no spring.
