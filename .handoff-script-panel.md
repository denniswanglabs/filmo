# Handoff — live "Script" panel feature

## Phase 1: DATA PLUMBING — DONE + VERIFIED

### New ledger field: `plan` (top-level)
Trimmed projection of the validated storyboard, written by `orchestrator.orchestrate()`
BEFORE any production work so it is visible while `phase=="planning"` and persists through
delivery.

Shape:
```json
"plan": {
  "voiceover": {"script": "<full VO narration>", "voice": "Adam"},
  "scenes": [{"id","type","model","duration_s","brief"}, ...]
}
```

### Files changed (phase 1)
- `orchestrator.py` — added `led.data["plan"] = {...}` projection + a "storyboard decided"
  info event, placed just before the first `set_phase("planning")` + `flush()` (so the
  planning ledger the UI polls already carries the script). Inserted right before the
  `# -- PLAN: validate` block (~line 118).
- `LEDGER.md` — documented the `plan` field: a top-level table row + a dedicated
  `### plan` subsection.

### Concern from brief — RESOLVED
build_runner.run() writes an initial 'planning' ledger, then orchestrate() builds its OWN
Ledger which supersedes it. The fix writes `plan` into orchestrate()'s ledger before its
FIRST flush (which is a planning-phase flush), so the script is never hidden. The
"storyboard decided" event is seq 1 — confirmed before "plan validated".

### Verification (run-id build-test-script-01, linear.app, mock, pace 0)
- ledger `plan.voiceover.script` carries a real 294-char Linear narration.
- `plan.scenes` = 6 ordered scenes, each with brief/type/model/duration_s.
- events seq 1 = "storyboard decided: 6 scenes, 294-char narration script".

## Phase 2: DASHBOARD — DONE + VERIFIED

### Files changed (phase 2)
- `dashboard/app.js`
  - `renderLive()` now inserts a "Script · the agent wrote it before shooting" section
    (between the agent grid and the storyboard) via new `liveScript(l)` + `initLiveScript(l)`.
  - `liveScript(l)` reads `l.plan`: a two-column `.script-grid` — left VO card (the
    narration in serif), right "Shot list" card (ordered scenes: brief + type/model/duration
    chips). When `plan` is absent (early planning, Nemotron still thinking) it shows a
    spinner: "the agent is still writing the narration…" / "deciding the shot list…".
  - `initLiveScript(l)` types the VO narration out ONCE, time-based via requestAnimationFrame
    (NOT setInterval — same headless/background throttle gotcha solved for typeCode).
    `state.scriptShown` guards against re-typing on every poll re-render; `beginPoll` resets it.
  - `toolForType()` maps free scene types to their tool label (matches orchestrator.adapters_tool)
    so title/walkthrough rows (model=null) show motion-graphics / walk-agent.
  - `state` gained `scriptTyper`, `scriptShown`.
- `dashboard/styles.css` — added the live SCRIPT panel block (`.script-grid`, `.script-card`,
  `.script-head` + `.badge`/`.badge.seq` letter badges, `.vo-script` serif copy, `.shot`/
  `.shot-n`/`.shot-brief`/`.shot-meta`/`.shot-tag`). Reuses existing tokens (amber accent,
  serif/mono, graphite ink). No emoji; uses the existing #i-loader SVG + VO/N letter badges.
