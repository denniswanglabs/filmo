## How it fetches pricing.json (single source of truth)
`loadPricing()` (called in `init()`) does `fetch("/pricing.json")` once, stores it
in `state.pricing`, and renders the menu. On failure the menu hides silently and
the build still works (backend falls back to `default_selection()`). NO numbers
are duplicated in JS — tier/booster prices, eligible_tiers, units, and
consent_required all read from the fetched file.

## The live-quote math (mirrors price_selection() EXACTLY)
`computeQuote()`: tier line (base_price/base_cogs) + one line per selected+eligible
booster, `price = unit_price * qty`, `cogs = unit_cogs * qty`,
`margin = (total_price - total_cogs) / total_price`. Per-unit qtys
(multi_format->formats, extra_language->languages, extra_revision->revisions) come
from `selection.options`; flat boosters qty=1. `renderQuote()` repaints on every
tier/booster/qty/consent change so the price climbs live.
Hand-verified vs pricing.json: Studio + rush + multi_format×2 + founder_voice =
**$434.00 (43400c), margin 0.804147** (matches the brief's known case); Starter
default = $19.00, 0.895; Starter + no_watermark = $29.00, 0.931.

## Consent guardrail UI (Contract 5)
Founder voice clone carries a lock icon + a nested consent block (only shown when
toggled on): attestation checkbox ("I attest I own or have permission to use this
voice."), a first-party owner text field, a one-line disclaimer ("First-party
only. We refuse cloning a public figure or any third party…"), and an inline
warning. Until `attested === true` AND a non-blank, non-placeholder owner is set,
founder_voice is EXCLUDED from the quote (blocked note shown), the Build button is
gated (`.pm-gated`), and `startBuild()` refuses with a nudge. The full
third-party/public-figure refusal heuristic stays server-side
(`pricing.validate_consent`); the UI enforces the two hard gates + a small
placeholder denylist. No third-party phrasing is encouraged anywhere. No emoji.

## How `selection` reaches the build
`startBuild()` calls `buildSelectionPayload()` (drops ineligible boosters, forces
per-unit qtys >=1 when on / 0 when off, normalizes consent) and adds it to the
existing POST body: `{ url, goal, mode, pace, selection }`. The producer prices it
via `price_selection()` when `WS_PREMIUM_MENU=1`.

## Eligibility behavior
Boosters not eligible on the current tier are checkbox-disabled and dimmed with a
"<tiers> only" note (e.g. on Starter only no_watermark is enabled; rush/founder/
multi/lang/revision need pro/studio). Switching tier drops now-ineligible selected
boosters so the live quote + payload stay server-valid.
