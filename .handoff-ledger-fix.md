## The fix (build_runner.py, run(), VO-engine block ~L257-279)
Before appending the VO-ENGINE event and writing, RELOAD the on-disk ledger that
orchestrate() just wrote:
```python
try:
    disk_led = ledger_mod.Ledger.load(led_path)
except (OSError, ValueError):
    disk_led = led  # no readable ledger on disk — keep the event somewhere
try:
    final = _run_vo_engine(...)
    if final: disk_led.event("info", "VO-ENGINE: rendered never-blank ...")
    else:     disk_led.event("info", "VO-ENGINE: engine render unavailable ...")
    disk_led.write(led_path)
except Exception as e:
    disk_led.event("info", "VO-ENGINE: skipped (%s) ..." % e)
    disk_led.write(led_path)
```

  delivered ledger (scenes=[], pnl=null, status stuck running/producing).
- Now: appends to `disk_led` (loaded from orchestrate's delivered ledger.json), so
  scenes/pnl/gate verdicts/status=delivered are PRESERVED + VO-ENGINE event added.
- Mirrors `_record_failure`'s reload-before-write. Inside try/except so engine issue
