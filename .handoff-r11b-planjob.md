## Detection extension (before → after)
Before, `_is_stage_direction_text` = prefix-start match (`_STAGE_DIRECTION_PREFIXES`)
OR substring-anywhere (`_STAGE_DIRECTION_SUBSTRINGS`, all colon-terminated). Two leaks
escaped: (1) "Closing call‑to‑action card urging users…" — opens with "Closing" (no
prefix) + fancy hyphen U+2011 defeated the ASCII "call-to-action" + the substring
needs a trailing colon; (2) "Call-to-action card using the brand color" — same.

Added (all in plan_job.py, extending the existing detection — no new rewrite path):
- `_norm_hyphens(s)` — lowercases + maps fancy unicode hyphens/minus
  (U+2010‐ U+2011‑ U+2012‒ U+2013– U+2014— U+2015― U+2212−) to ASCII '-'.
- `_META_DESCRIPTION_SUBSTRINGS` — the meta-description class: call-to-action,
  call to action, closing card, closing call, urging users, card urging, cta card,
  the cta, using the brand, brand color, the wordmark, stage direction.
- `_STAGE_OPENER_VERBS` (closing/show/display/animate/present) + `_STAGE_SCENE_NOUNS`
  (card/scene/title card/cta/lockup/wordmark/…): a beat that STARTS with an opener
  verb AND names a scene/card noun is flagged. The noun requirement preserves legit
  copy ("Show your work to the world", "Closing time" → NOT flagged).
- `_is_meta_description_text(norm)` runs the above on the hyphen-normalized text.
- `_is_stage_direction_text` now also returns True when
  `_is_meta_description_text(_norm_hyphens(t))` fires.

Rewrite path UNCHANGED — `_degut_stage_direction_beats` already reuses
`_grounded_template_beats`; the extended predicate just feeds it more catches.
CTA-shaped beats → grounded CTA line; non-CTA → grounded open/home line.
