## 2. Current request mechanism (what to reuse)

The planner request is built in **`validate_planner.py:116-145` `call_model()`** using **stdlib `urllib.request`** (NOT `requests`):

- `API_URL = "https://integrate.api.nvidia.com/v1/chat/completions"` (`validate_planner.py:15`)
- `MODEL = "nvidia/nemotron-3-super-120b-a12b"` (`validate_planner.py:16`)
- key from `os.environ["NVIDIA_API_KEY"]` (`validate_planner.py:117-119`)
- payload: `{"model": MODEL, "messages": ..., "temperature": 0.2, "max_tokens": 8000}`
- headers: `Authorization: Bearer <key>`, `Content-Type: application/json`, `Accept: application/json`
- `urllib.request.urlopen(req, timeout=300)`, OpenAI-shaped response `body["choices"][0]["message"]["content"]`.

OpenRouter is OpenAI-compatible: same body, same response shape. ONLY base URL + model slug + auth key change. So the implementation is a drop-in: point `API_URL` at `https://openrouter.ai/api/v1/chat/completions`, swap the model slug, and read `OPENROUTER_API_KEY`.

`plan_job.py` does NOT build its own request — `_plan_with_nemotron` (`plan_job.py:203-226`) reuses `vp.SYSTEM_PROMPT`, `vp.call_model`, `vp.extract_json`. So **changing `validate_planner.call_model` propagates to the live build planner automatically.** The two eval scripts (`hermes_judgment_eval.py:28-29,87-105`, `hermes_skill_eval.py:23-24,98-115`) each have their OWN copy of `API_URL`/`MODEL`/`call_model` and must be updated independently.

## 4. Brain-config — single source of truth (NEW FILE `brain.py`)

Create `/Users/dennis/Desktop/Projects/Hackathons/hermes-video-agent/brain.py` (stdlib only, mirrors `plan_job.VALID_STYLES`/`VALID_QUALITIES` style):

```python
#!/usr/bin/env python3
"""Single source of truth for the PLANNER BRAIN — the LLM that plans the storyboard.

Operator-selectable, EXACTLY three options, all routed through OpenRouter
(OpenAI-compatible). This is NOT scene["model"] (the seedance/gpt_image media
generators); it is the LLM that decomposes a brief into a scene plan.

Default = super-free ($0) so a build never accidentally bills planner tokens.
"""
import os

OPENROUTER_URL = "https://openrouter.ai/api/v1/chat/completions"

# key -> {label, slug, paid, price per 1M tokens (prompt, completion)}
BRAINS = {
    "ultra-paid": {
        "label": "Nemotron 3 Ultra (paid)",
        "slug": "nvidia/nemotron-3-ultra-550b-a55b",
        "paid": True,
        "price_per_1m": {"prompt": 0.50, "completion": 2.20},
    },
    "super-free": {
        "label": "Nemotron 3 Super (free)",
        "slug": "nvidia/nemotron-3-super-120b-a12b:free",
        "paid": False,
        "price_per_1m": {"prompt": 0.0, "completion": 0.0},
    },
    "super-paid": {
        "label": "Nemotron 3 Super (paid)",
        "slug": "nvidia/nemotron-3-super-120b-a12b",
        "paid": True,
        "price_per_1m": {"prompt": 0.09, "completion": 0.45},
    },
}

DEFAULT_BRAIN = "super-free"
VALID_BRAINS = tuple(BRAINS.keys())

def normalize_brain(brain):
    b = str(brain or "").strip().lower()
    return b if b in BRAINS else DEFAULT_BRAIN

def brain_def(brain):
    return BRAINS[normalize_brain(brain)]

def brain_endpoint():
    return OPENROUTER_URL

def brain_key():
    """OpenRouter key. zsh -lc / source ~/.zshrc both provide it."""
    return os.environ.get("OPENROUTER_API_KEY")
```

Design choice: keep the brain **selectable per-call via a parameter threaded through the planner**, defaulting to `DEFAULT_BRAIN`. Do NOT read a global env var for the choice (the operator picks it in the UI per build). The IMPLEMENTATION must NOT break the existing deterministic-template fallback — that path is `plan_job.py:84-86` (`_plan_with_nemotron` returns `None` on any failure → `_template_plan`). Preserve it exactly.

## 7. COGS / cost-plus note (small, but RECOMMENDED to keep cost-plus honest)

How planner cost is counted today: **it is NOT.** `producer.cmd_estimate` (`producer.py:197-252`) sums ONLY scene media (`estimate_scene_cents`, seedance/gpt_image) + voiceover (`estimate_voiceover_cents`, ElevenLabs). Remotion/edge-tts/walk-agent are free; **the planner LLM call is nowhere in `total_cogs_cents`.** `pricing.price_for_plan(plan_cogs_cents, quality)` just marks up that COGS. So with `super-free` (the default) there is genuinely $0 planner cost and nothing to add. With `super-paid`/`ultra-paid`, real planner tokens are spent but currently invisible to COGS.

Two-tier recommendation:
- **Default path (super-free): nothing to do** — $0 planner cost, cost-plus stays honest as-is. This is the only path that runs unless the operator deliberately flips to a paid brain.
- **Paid brains: add a `plan_cogs` line — but flag as a SEPARATE FOLLOW-UP, not bundled.** Doing it right means capturing the planner call's `usage.prompt_tokens`/`completion_tokens` (the response already returns `usage` — see `validate_planner.py:144`), multiplying by `brain_def(brain)["price_per_1m"]`, converting to cents, and threading that into `total_cogs_cents` before `price_for_plan`. That touches `validate_planner.call_model` (return usage), `plan_job` (propagate), `build_runner._price_plan`, and `producer.cmd_estimate` — i.e. the whole pricing spine. **This is more than a small change and is OUT OF SCOPE for the toggle task. File it as a follow-up: "Add planner-token COGS for paid brains so cost-plus stays honest."** The toggle ships safely without it because the default brain is free.
