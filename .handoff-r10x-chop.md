## What landed (style_fill.py ONLY)
- `_DANGLING_WORDS`: + possessives/determiners ("your","its","their","our","his","her",
  "my","this","these","those"), + conjunctions ("but","so","nor","yet"), + "whose"/"whom".
- NEW `_DANGLING_PARTICIPLES`: clause-bridge participle-helpers ("letting","keeping",
  "making","allowing","enabling"...) that must not END a headline.
- NEW `_strip_dangling_tail(text)`: drops trailing comma + any dangling tail (function
  word / possessive / participle-helper) so the phrase ends on a CONTENT word. Idempotent.
- NEW `_split_first_sentence(text)` + `_SENTENCE_BOUNDARY_RE`: a "." is a sentence
  boundary ONLY when followed by whitespace/EOS — a "." inside a domain ("theverge.com")
  is NON-terminal → ".com" preserved. `_title_from_text` now uses it (was splitting on
  bare `[.!?\n]`, the CTA-domain bug).
- NEW `_first_complete_clause(text, limit)`: prefer the FIRST COMPLETE CLAUSE that fits
  (cut at comma/semicolon/colon OR before a relative/participle clause-opener) over a
  hard mid-clause chop. Wired into BOTH `_title_from_text` and `_punchy_headline`'s
  `_was_truncated` branch.
- Section-label opening title: R9 `_looks_like_headline` gate UNCHANGED (already rejects
  "Quick Posts"/"Featured" → grounded value-prop); locked with new tests.
