## The v3 refinement (establish track only)

### New helper: `_color_name(hex)`
Maps a `#RRGGBB` hex to a coarse human color name via a 12-name HSV hue wheel
(red/orange/amber/yellow/lime green/green/teal/blue/violet/magenta/pink). Hue
from HSV, so the name tracks the brand identity regardless of how dark/muted the
original is. Returns `""` for pure-grey (sat ≤ 0.08), near-black (val ≤ 0.06),
or unparseable input (caller then falls back to hex-only phrasing). Never raises.
- Verified: `#5E8E3E`→green, `#00C805`→green, `#76B900`→lime green,
  `#635BFF`→blue, `#FF5A1F`→orange, `#808080`/`#000000`/garbage→"".
- Hue-preserving through saturation: `_color_name(h) == _color_name(_saturate_hex(h))`
  for `#5E8E3E`/`#95BF47`/`#76B900` (the name survives the iter-5 boost).

### New builder: `_color_dominance(name, hexes)`
Returns the whole-frame grade phrase, anchored on the PRIMARY (first) accent:
> "`<name>`-dominant color grade, the entire scene bathed in `<name>` light
> (`<sat-hex>`), `<name>` glow tinting the volumetric haze, the reflections and
> the background, `<name>` as the single dominant color of the whole frame"

If `name` is `""` (unnameable hue), falls back to "brand-accent-dominant … the
brand accent as the single dominant color of the whole frame" (still whole-frame,
no hex/name). Phrased ENTIRELY in abstract light/haze/reflection/background
language — NO text noun — so the no-positive-text-noun rule holds.

### Wiring (`cinematic_prompt`, establish track)
Injected immediately AFTER the existing saturated-hex palette line (which is kept
intact) and BEFORE the abstract anti-text body, gated on `if hexes:` (so no
accent → no palette line AND no dominance grade). Anchored on the primary
`accent` via `_color_dominance(_color_name(accent), hexes)`.
