# R9 — OPENING hero title from grounded value-prop (style_fill.py ONLY)

## Goal
Make the OPENING hero title robust for ANY brand by deriving it from the GROUNDED
value-prop (the planner's opening VO beat), NOT scraped feature/section labels.
Replace the negative nav-label DENYLIST with a POSITIVE headline test.

## Root cause (confirmed from runs/r8-allbirds)
- brand_theme tagline = truncated meta fragment → rejected.
- brand_theme features = ['Popular Picks', "Men's", "Women's", 'All Sale'] — all
  nav/section labels.
- grounded opening VO beat = "Allbirds makes comfortable shoes from natural,
  sustainable materials." → threaded to timeline.scenes[0].text → `raw_threaded`
  / `d["_text"]` in `_shape_hero`.
- BUG: when raw_title==wordmark, `_distinct_tagline(brand)` synthesizes
  "Popular Picks" from features (passes the old guards) and WINS, even though the
  grounded VO is sitting right there in `raw_threaded`. Rendered: title="Popular
  Picks", subtitle="All Sale".

## Plan (style_fill.py only, $0)
1. Add `_looks_like_headline(text)` POSITIVE test: a scraped phrase is eligible as
   the title ONLY if it reads like a real headline/value-prop — has a verb OR is a
   full clause/sentence (not a short Title-Case noun phrase). Short Title-Case
   noun-phrase labels (Popular Picks, Customer Favorites, New Arrivals, Best
   Sellers, Featured, Shop All, Help Center, Men's Shoes, Gift Guide, Top Rated) →
   NOT eligible.
2. Add `_grounded_headline(brand, raw_threaded)`: distill the grounded opening VO
   beat into a punchy headline (reuse _punchy_headline + entity-decode + clause-end
   guards), else "".
3. Rewrite `_shape_hero` OPENING branch: when raw title == wordmark OR no real H1,
   DERIVE title = grounded_headline(raw_threaded) → world-knowledge tagline →
   wordmark. NEVER pick/synthesize the opening title from scraped section labels.
   Gate any scraped-candidate path through `_looks_like_headline`.
4. Subtitle: must not be a bare section label (already partly guarded; ensure
   `_looks_like_headline`-failing section labels are dropped).
5. PRESERVE all prior wins: ·/•/| nav-join reject, entity-decode, clause-end,
   genre framing, R8 wordmark + nav-join reject, single-word brand names, accents.

## Status: DONE — implemented + verified isolated ($0), all tests green.

## What landed (style_fill.py only)
- NEW `_looks_like_headline(text)` — POSITIVE test: eligible as title ONLY if it has
  a verb (known-verb set OR lowercase -ing/-ed morphology) OR is a full clause
  (terminal punct, a clause-signal pronoun/aux in a >=3-word phrase, OR a lowercase
  interior content word = sentence-cased). Rejects the WHOLE class of short Title-Case
  noun-phrase section labels. Verified: 0 misclassified across the spec set + extras.
- NEW `_grounded_headline(raw_threaded, brand, avoid, limit)` — distills the planner's
  opening VO beat via _punchy_headline (+ clause-end/numeral guards), else the
  world-knowledge/real tagline, else "" — each candidate gated through
  _looks_like_headline.
- NEW `_is_section_label_subtitle(text)` — narrow subtitle guard: rejects a <=3-word
  PURE Title-Case section label ("All Sale") but KEEPS a sentence-cased value-prop
  tagline ("On-demand manufacturing").
- `_punchy_headline`: added a DANGLING-PREP-PHRASE guard that fires ONLY on actual
  truncation — backs up off a clipped "PREP + lone object" tail ("...shoes from
  natural" -> "...shoes"). Naturally-complete tails ("made from wool") preserved.
- `_shape_hero` OPENING branch REWRITTEN: explicit plan title used ONLY if it passes
  _looks_like_headline; else DERIVE from grounded value-prop -> world tagline ->
  wordmark. NO MORE _distinct_tagline (feature-label synth) for the TITLE — that was
  the "Popular Picks"/"All Sale" bug. R8 nav-join reject kept as belt-and-suspenders.
  Subtitle gated by _is_section_label_subtitle in addition to the prior guards.
