## The 3 refinements (establish track only)

### 1. Single-hero / clean-composition cue
New `_SINGLE_HERO` constant, appended right after the cinematography scaffold:
> "a single hero object as the sole focal point, clean uncluttered composition,
> one device or product silhouette, no array of cards, no grid of panels, no
> multiple stacked UI windows"

Biases POSITIVELY to one focal object and NEGATES the multi-element "array of
cards / grid of panels" layouts that reintroduced the Shopify bottom caption-strip
garble in iter-5.

### 2. Never name a UI-text noun positively
- OLD `_ANTI_TEXT` said "all interface **text** illegible …" — it NAMED "interface
  text", and naming text (even qualified) cues the model to render it.
- NEW `_ANTI_TEXT` is purely abstract light/shape language:
  > "surfaces carry only soft diffuse light, gentle glow and creamy bokeh,
  > abstract luminous shapes melting into shallow-focus blur"
- The hard no-text steer now lives ONLY in a new TRAILING pure-negative clause
  `_NO_TEXT`: "no text, no words, no letters, no wordmarks, no watermarks, no UI
  labels".
- `_TITLE_ROOM` was also rewritten to drop the "UI elements" phrasing → abstract
  ("wide open negative space reserved for a title overlay, the hero object
  resolving in the lower third with soft glow drifting around it").
- Net: the only place ANY text noun appears is inside the trailing exclusions.

### 3. Saturated / vivid brand hex
- New helper `_saturate_hex(hex, min_sat=0.85, min_val=0.55)` — HSV round-trip
  that raises saturation (and lifts very dark value) to a floor while PRESERVING
  hue; never lowers S/V, never raises a pure grey (sat==0), never raises on
  garbage input (returns stripped/uppercased).
- `cinematic_prompt` now injects `_saturate_hex(accent)` / `_saturate_hex(accent2)`
  and prefixes the line with "**vivid saturated** brand-accent palette: …".
- Why: iter-5 Shopify olive `#5E8E3E` read as ORANGE because the desaturated hex
  under-steered; Robinhood's vivid `#00C805` steered reliably.
