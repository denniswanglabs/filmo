## What changed (the restructure)
Round 1 was a 2-pane editor (preview left, panel right). Round 2 rebuilds it into a real
**iMovie-style timeline video editor** with **Hera's** premium design language:

  ┌── floating glass TOP BAR (wordmark · run picker · Save · gradient Export · status dot) ──┐
  │  PREVIEW STAGE (hero)                                    │  INSPECTOR (glass aside)        │
  │   format/duration pills → framed dark canvas (Player)   │  selected scene: geometry /     │
  │   → glass control pill (rewind · play/pause · scrub)    │  text / lists / timing / theme  │
  │  BOTTOM TIMELINE (glass): ruler + scene CLIPS ∝ duration │                                 │
  │  (thumbnail + label + index) + live playhead            │                                 │
  └─────────────────────────────────────────────────────────┴─────────────────────────────────┘

## Files
- `index.html` — NEW Hera tokens: glass surfaces (`--glass`, blur 22px), ambient aurora body
  backdrop, heavier radius scale (`--r-ctl`12 / `--r-card`18 / `--r-lg`22), gradient accent
  (`--accent-grad`) + strong glow, `.ws-glass` utility, `.ws-scrub` seek-bar CSS, `ws-breathe` kf.
- `src/ui.jsx` — new icons (play/pause/rewind/sliders/type/palette/clock/list); primary Button now
  uses `--accent-grad` + glow + inset highlight; added `kind="glass"`; Section accepts an `icon`.
- `src/TimelineTrack.jsx` — NEW. The bottom track. Clips positioned/sized by % of total duration
  (width ∝ out−in). Each clip = a `<Thumbnail>` of its first frame (in_frame+3) + archetype glyph +
  label + index chip, with scrim for legibility. Selected = accent ring + glow; hover = lift. Live
  playhead (accent line + dot) tracks `currentFrame`. Subtle m:ss ruler above. Click → onSelect(i).
- `src/PlayerControls.jsx` — NEW. Glass pill under the canvas: rewind, big gradient round play/pause,
  current/total timecode (tabular), scrub bar. Subscribes to player events
  (play/pause/ended/frameupdate/seeked) to stay in lockstep; scrub calls `seekTo`.
- `src/App.jsx` — rebuilt composition. Floating glass header; preview stage with pills above +
  controls below; bottom timeline section; right glass inspector. NEW: `frame` state (live playhead)
  + `selectScene(i)` which sets activeIdx AND `player.seekTo(scene.in_frame)` + pauses.
- `src/EditPanel.jsx` — removed the in-panel scene list (the TIMELINE replaces it). Added a sticky
  "Inspector" header, a gradient-tinted active-scene card, and section icons. Same edit controls.

## Data flow UNCHANGED — all live-edit + Save/Export intact
