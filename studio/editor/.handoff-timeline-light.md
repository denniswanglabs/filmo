# Handoff — Timeline track goes light

## Goal
The bottom TIMELINE track had a black trough that clashed with the light editor.
Changed it to an off-white well and re-tuned everything that sat on it so it reads
as the same light product. The VIDEO PREVIEW STAGE stays dark (untouched).

## Files touched (backups: `<file>.pre-timeline-light.bak`)
- `studio/editor/index.html` — `:root` timeline tokens + 2 comment lines
- `studio/editor/src/TimelineTrack.jsx` — trough, clip cards, scrim, chip, labels

## Token changes (index.html :root)
- `--rail`  `#0C0E12` (black) → `#F7F8FA` (off-white recessed well, = `--bg-2`)
- `--clip`  `#14171C` (dark block) → `#FFFFFF` (clean white card)
- `--clip-2``#1B1F27` (dark hover) → `#F7F8FA` (off-white hover well)
- Header comments updated: removed the "(and the timeline track trough) stay dark"
  claim and added "TIMELINE track is now light; only the VIDEO stage stays dark".

## TimelineTrack.jsx re-tuning
- **Trough**: border `--line-2` → `--line` (hairline); inset shadow flipped from a
  heavy dark `rgba(0,0,0,.6)` to a faint light recess
  `inset 0 1px 0 rgba(255,255,255,.6), inset 0 2px 8px -6px rgba(20,23,28,.10)`.
- **Clip cards**: now the dashboard card recipe — `--clip` (white) fill, `--line`
  hairline (hover `--line-2`), soft NEUTRAL shadow
  (`0 1px 2px rgba(20,23,28,.05), 0 6px 16px rgba(20,23,28,.07)`; hover lifts).
  Removed the old dark `rgba(0,0,0,.7-.85)` shadows.
- **Active/selected clip**: keeps coral — `--accent-line` border + coral glow
  shadow `0 6px 16px rgba(214,53,28,.20)`. Placeholder fill for active uses
  `--accent-tint-2 → --accent-tint` (soft coral wash) instead of the old hardcoded
  `rgba(214,53,28,.28)`.
- **Dark scrim**: now rendered ONLY when a thumbnail is present (`showThumb`). Over
  imagery the bottom-edge scrim keeps labels legible as light text. Narrow
  placeholder clips (no thumbnail) get NO scrim so they read as light cards.
- **Two ink schemes** via `const onDark = showThumb`:
  - thumbnail clips (onDark): light text + drop shadow as before (`#fff`/`#dde3ee`
    title, `#9aa6b8` meta, dark glass index chip).
  - placeholder light clips: dark ink — title `--text` (active `--accent-deep`),
    glyph `--muted`, meta `--dim` (active `--accent`), index chip = `--bg-2` well +
    `--muted` ink + `--line` border; text shadows dropped.
- **Ruler ticks / time labels**: already `--dim` (`#98A1B0`, the token literally
  spec'd "ruler ticks") and sit on the page bg, not the trough — readable on light,
  left unchanged.
- **Playhead**: unchanged — stays `--accent` coral with coral glow.

## Preview stage
