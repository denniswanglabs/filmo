# Handoff — scene-aligned voiceover

## Goal
Fix VO/video desync (VO-MISMATCH-ANALYSIS.md): single flat track muxed at t=0,
no per-scene alignment → CTA over walkthrough, ~9.5s silent tail.

## Phase 1 — schema + helpers (DONE)
- `plan_schema.py`: voiceover now carries `beats: [{scene_id, text}]`.
  - `validate_plan` accepts beats OR legacy `script`; checks scene_id membership.
  - Added `resolve_vo_beats(plan)` (new beats as-is; legacy script split across
    scenes, tail folds into last scene) + `vo_script_from_beats(beats)`.
- `validate_planner.py`: `schema_check` requires `beats` (1 per non-title scene,
  scene_id ∈ scenes). SYSTEM_PROMPT emits beats; max_tokens stays 8000.
- `planner-prompt.md` + `SCHEMA.md` + `example-plan.json`: updated to beats schema
  + documented fallback. max_tokens note bumped to 8000.
- `plan_job.py`: `_template_plan` fallback emits per-scene beats.

## Phase 2 — synth + placement (DONE)
- `adapters.py`: added `synthesize_voiceover_aligned(beats, voice, out_path,
  provider, total_s)`. Synthesizes EACH beat to its own mp3 (reuses existing
  edge/elevenlabs switch), then adelay's each to its scene `start_s` and amix's
  into ONE full-length `voiceover.mp3` (apad+`-t total_s`). Persists per-beat
  segments as `voiceover.beatNN.mp3`. Returns `segments:[{scene_id,start_s,path,dur_s}]`.
  Old `synthesize_voiceover` kept.
- `orchestrator.py`:
  - resolves beats (`resolve_vo_beats`), mirrors derived `script` into written plan
    (so producer.py cost + build_runner projection keep working).
  - computes produced-clip start offsets (cumulative durations); DROPS beats whose
    scene didn't produce a clip (cut/declined). Logs dropped beats.
  - VO-approved + beats → `synthesize_voiceover_aligned`. No beats → HEDGE: single
    track anchored to first PRODUCED content scene offset (not t=0).
  - ledger voiceover rec carries beats_total/beats_aligned/beats_dropped/segments.
- `finish_cut.py`: when ledger has `voiceover.segments`, re-places each beat at its
  scene's CROSSFADE-timeline offset (re-uses persisted beat mp3s); else legacy
  single-track 350ms path. Sidechain-duck infra reused.
