## DIAGNOSIS (confirmed)
### Bug 1 — nav-label title via separator (HIGH)
- Rendered: `runs/g7-allbirds/props.json` `scenes[0].data.title = "Men's Shoes · Customer Favorites"`,
  `runs/g7-airbnb` `= "Help Center · Find a co-host"`. Subtitle = first feature ("Men's Shoes" / "Help Center").
- Separator codepoint: **U+00B7 (middle dot `·`)** with surrounding spaces (` · `).
- EXACT codepath: `style_fill._distinct_tagline()` step 2 SYNTHESIZES `" · ".join(short)` from
  `brand["features"][].title`, which for these brands are nav-section labels
  ("Men's Shoes", "Customer Favorites", "Help Center", "Find a co-host"). Returned as the OPENING title via
  `_shape_hero` (raw_title == wordmark → `_distinct_tagline(brand, avoid=wordmark)`).
- WHY it bypassed G2: `_is_ui_nav_label` correctly returns True for the join, but it was applied only to
  INPUT titles, never to `_distinct_tagline`'s synthesized OUTPUT. Source: `brand_extract._is_ui_label`
  failed to drop "Men's Shoes"/"Help Center"/etc. from features (not in `_UI_LABEL_EXACT`).

### Bug 2 — "Theverge" collapsed wordmark (MED)
- `extract_brand` name = `palette._name` = "Theverge" (host label, space-stripped). Refinement at
  the og:site_name block required `label.lower() in fetched.lower()` → `"theverge" in "the verge"` = False
  (space) → "The Verge" rejected, name stays "Theverge" → kicker "THEVERGE".
