## Files changed
- `build_timeline.py` — `_derive_role`: a TITLE/hero/intro scene whose id contains
  a closing marker (`clos`/`cta`/`outro`/`end`, via `_CLOSING_ID_HINTS`) now derives
  role `"close"` instead of `"title"`. This is the ONLY signal that separates the
  opening title from the closing title (both carry type "title"). Role `close`
  still routes to ARCH_HERO in style_fill's role_map, so the closing stays a hero
  but is shaped as a CTA.
- `style_fill.py`:
  - new `_is_closing_title(scene)` — closing when `data._is_closing` flag set
    (build_props marks the FINAL hero scene), OR role in
    `{close,cta,closing,outro,end}`, OR id contains `clos/cta/outro`.
  - `_shape_hero` split into OPENING vs CLOSING:
    - OPENING (unchanged): kicker=WORDMARK upper, title=brand tagline, sub=tagline.
    - CLOSING: kicker="" (so the wordmark is NOT echoed as the eyebrow),
      title=the scene's threaded VO/brief closing line (the real CTA), sub=brand
      cta_url (fallback tagline). HeroTitle.tsx already draws theme.wordmark as a
      small navy sub-line above the title whenever wordmark != title, so the
      wordmark shows ONCE (sub-line) and the CTA is the headline. Never twice.
  - new `_match_feature` + `_feature_tokens` (+ `_FEATURE_STOPWORDS`) — token-overlap
    match of a feature label against the scene's spoken/brief/title text.
  - `_shape_explainer` bullets: lead with the keyword-matched feature for THIS scene
    (CNC scene -> "CNC Machining" first, laser scene -> "Laser Sintering" first),
    falling back to a positional rotation by `data._feature_index` when no keyword
    matches. Only REORDERS real fixture features; never fabricates. Full real list
    still shown so scenes read as a set.
  - `build_props` loop now: enumerates scenes (idx/last_idx), threads
    `data._is_closing=True` onto the final hero scene, and `data._feature_index`
    (0-based order among explainer scenes) onto each explainer. Internal `_`-keys
    are consumed by the shapers and NOT emitted into props.data (verified no leak).
