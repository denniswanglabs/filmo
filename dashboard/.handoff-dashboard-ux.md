## Task 1 — Edit-video deep-link bug — ROOT CAUSE CONFIRMED
- Dashboard runs (`/runs/index.json`) use ids like `build-notion-0da497`, `build-linear-54d446`, `demo-1-approve`.
- Editor runs API (`/api/editor/runs`) only lists runs that have `runs/<id>/props.json` (serve.py `_editor_list_runs`, ~line 385-411).
- 22 DELIVERED dashboard runs have `final.mp4` but NO `props.json` → NOT in editor API:
  build-linear-54d446, build-luceostudio-617a04, build-notion-0da497, build-stripe-9e7829,
  demo-1-approve, demo-2-downgrade, demo-3-decline, demo-4-vo-over, hermes-driven-01,
  iv-legacy-201755, iv-premium-gateproof-201641, ledgerfix-off-202609, moneyshot_dryrun,
  moneyshot_live, overnight-figma-{cinematic,snappy,standard}, overnight-style-{cinematic,snappy,standard},
  premium-demo-01, sample-plan.
- Editor App.jsx deep-load (lines 124-128): `(deepLink && list.find(r=>r.id===deepLink)) || list.find(r=>r.id===DEFAULT_RUN) || list[0]`.
  When deep-linked run is absent from `list`, it silently falls to DEFAULT_RUN → "another video." THIS is the bug.

### Dashboard-side fix (chosen — zero extra clicks, never silent-wrong):
- `deliveredHero()` (app.js ~668-673) Edit button is made data-aware: only a real link when the run is editor-loadable; otherwise a clearly disabled control + inline note. Dashboard caches `/api/editor/runs` id set in `state.editorRuns`, loaded once in `selectRun` before `renderDetail`.

### Editor-side fix recommended for orchestrator (NOT applied by me — I don't own studio/editor):
Make the editor warn instead of silently falling back. In `studio/editor/src/App.jsx` ~124-129, when `deepLink` is set but not found in `list`, call `note("That video isn't editable yet (no props.json) — opened default instead", "error")` rather than silently loading DEFAULT_RUN; ideally `loadRun(deepLink)` directly and let `/api/editor/props` surface the error inline. Requires `cd studio/editor && npm run build` to take effect.
Deeper root fix (server/pipeline, owned elsewhere): emit `props.json` for ALL delivered runs so every delivered build is editable.
