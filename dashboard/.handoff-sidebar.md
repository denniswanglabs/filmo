# Sidebar refinement → Claude-level minimalism

Date: 2026-06-21. Touched ONLY sidebar markup/CSS/JS. Server (:3030) left untouched.

## Files edited (backups written)
- `app.js` + `app.js.pre-sidebar.bak`
- `styles.css` + `styles.css.pre-sidebar.bak`
- `index.html` + `index.html.pre-sidebar.bak`

## What changed

### Row design (app.js)
- `renderRail()` rewritten. Each past-build row is now ONE clean single line: a
  human brand TITLE only. Removed from the row: raw run-id, MOCK/REAL badge,
  margin %, gross $. (Those still live in the build's detail view — verified
  intact: clicking Linear opens its delivered hero + P&L with margin/price.)
- New `railRow(r)` builds the row; new `railTitle(r)` derives the title; new
  `brandFromHost(host)` extracts the registrable brand label.
- TITLE derivation priority: (1) `company_url` host → registrable brand label
  (the dotted segment before the public suffix, handles 2-part suffixes like
  co.uk/com.tw) so `docs.stripe.com`→"Stripe", `linear.app`→"Linear",
  `notion.so`→"Notion", `www.orinovate.com`→"Orinovate"; (2) fallback to run-id
  slug (strip `build-` prefix + trailing hex hash) e.g. `build-orinovate-edf804`
  →"Orinovate". Title-cased, `-_.`→space, `clip()`-truncated to 30 chars.
- Only extra signal: a 6px status DOT, shown ONLY for non-delivered builds
  (running/awaiting=coral, failed=red, other=grey). Delivered rows = title only.

### Recency grouping (app.js)
- New `railGroup(ts)` buckets by `created_at`: Today / Previous 7 days / Older.
  Runs without a usable timestamp → quiet "Recents". If NO run has a timestamp,
  the whole list collapses to a single "Recents" section (no false day labels).
  index.json today: 4 demos have created_at (→"Previous 7 days"), rest null
  (→"Recents"). renderRail emits a `.rail-group` label div per bucket.

### Interactions (styles.css)
- Rows: no cards/borders. Soft `--bg-2` hover + active fill; active title bolds
  to ink. Title is single-line, ellipsis, `nowrap`.
- Delete: hover-revealed (`opacity:0` default → 1 on `.run-wrap:hover` / focus),
  small ghost trash centered at row right, warms to red on hover. PRESERVED the
  two-step confirm (`askDelete`/`confirmDelete`, POST /api/delete) unchanged.
- `selectRun`, the New-build button, sidebar collapse/reopen: untouched.

### Chrome (index.html + styles.css)
- Removed the always-on "BUILDS" head + count and the tech-stack line. Kept the
  Walk Studio logo, "New build", and a minimal footer (conn dot + quiet SYNC).
- `#rail-stats` kept but `hidden` so app.js's existing `.textContent` wiring
  stays valid (setConn still updates conn-text). Old `.rail-head/.rail-title/
  .rail-count/.rail-stack` rules + dead `.rc-goal/.rc-stats/.rc-margin/.rc-price/
  .rc-flag/.rc-status/.rc-top/.rc-id/.rc-mode` rules removed; added `.rail-group`,
  `.rc-title`, `.rc-dot`, `.rail-sync`.
