Real visual capture (not WebFetch text). This is the reference for Filmo's landing rebuild.

## The "moving windows as you scroll" = two distinct effects
1. **Scroll-pinned animated editor (hero).** The hero is a large, realistic **product-editor mockup** — left vertical toolbar (icon rail), a 16:9 canvas, a bottom **prompt bar that auto-types** a prompt ("C" → "An…"), and top controls ("Widescreen 16:9 ▾ / 15 seconds ▾"). It stays pinned/centered while the prompt types itself. Feels alive immediately — the product demos itself.
2. **Parallax template columns (the showpiece).** Below the hero, a multi-COLUMN gallery of video-thumbnail cards (rounded black tiles) where **columns drift vertically at different speeds/directions as you scroll** — the signature "windows moving" effect. Centered "Browse 100+ templates" pill button overlaid. THIS is the element Dennis loves most.

## Page structure (top → bottom)
1. **Floating pill nav** — Hera logo (left) + Examples / Testimonials / API (center) + "Start creating" gradient button (right). Translucent **dark** rounded bar that floats; stays sticky and goes darker/blurred over content on scroll.
2. **Hero** — the pinned auto-typing editor mockup (above).
3. **Template gallery** — parallax drifting columns of video cards + "Browse 100+ templates".
4. **Testimonials** — horizontal **marquee** of real creator quote cards (quote + avatar + @handle), auto-scrolling sideways.
5. **"Ready to create?"** — big bold closing headline on a dark band + CTA.
6. Footer.

## Visual DNA
- **Background is DARK charcoal (~#1a1a1a)** with **light/black product windows floating in it** — the depth comes from dark canvas + floating cards. (Filmo is currently light + Coinbase blue — this is the main fork: do we take Hera's dark stage, or keep light?)
- **Logo** = compact **abstract cluster** — 4 rounded coral shapes (2 circles + 2 rounded-squares) packed tight, sitting **snug against** the "Hera" wordmark (small gap). Confirms Dennis's "abstract + closer" direction.
- Accent = warm **gradient** (coral → pink → amber) on the primary button. Big bold sans headlines. Generous dark whitespace.
- Everything is **product-forward**: the hero IS the editor; the gallery IS the outputs. Very little marketing copy — the product demos itself.
