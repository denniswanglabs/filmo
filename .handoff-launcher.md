# Handoff — Walk Studio desktop launcher

_Created 2026-06-21. Deliverable: `~/Desktop/start-walk-studio.command` (executable)._

## What it is
A double-clickable macOS launcher Dennis runs after a reboot to bring up the FULL
Walk Studio stack durably. Fixes the root cause: the dashboard server (:3030) was
ephemeral, so when Stripe redirected the paid customer back to
`http://localhost:3030` nothing answered and the page went blank.

## What it starts (in order)
1. **Dashboard server on :3030 — DURABLE.** `nohup python3 dashboard/serve.py >> logs/dashboard.log 2>&1 &` then `disown`, so it survives the Terminal window closing. This is the whole point: keep :3030 answering for the Stripe return URL.
2. **Walk-agent / NemoClaw readiness — BEST-EFFORT, NON-FATAL.** Health check `nemoclaw walk-ultra exec --no-tty -- true`; on failure runs the documented warm-up `nemoclaw credentials reset nvidia-prod --yes` + `nemoclaw onboard --non-interactive --yes`, then re-checks. Every step bounded (`perl -e 'alarm N; exec @ARGV'`) so it never hangs. Dashboard comes up even if this whole section fails.
3. **Opens the dashboard in Safari** (`open -a Safari http://localhost:3030`).

## Durable + idempotent
- **Durable:** nohup detaches from SIGHUP; `disown` removes the job from the shell table so closing the Terminal does not kill it.
- **Idempotent:** `dash_alive()` checks :3030 first (HTTP curl probe, falling back to `lsof`). If already serving it prints "already running" and does NOT start a second server. Safe to double-click repeatedly. No port-in-use error spam.
- **Env:** sources `~/.zshrc` for `NVIDIA_API_KEY` (verified by length only, never echoed). `export BROWSER=none` so better-opn never pops a "Where is Arc?" dialog.
- **Skip flag:** `SKIP_WALK=1` skips the entire walk-agent section.
- **No emojis** in output (house rule). Uses `[ok]/[..]/[warn]` prefixes.
