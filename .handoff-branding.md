## What changed (exact elements/strings)
1. **`index.html` `<title>`** (~line 6):
   `Hermes — Producer Console` → `Walk Studio — Producer Console`.
2. **Favicon** (new `<link rel="icon" ...>` added right after `<title>`):
   data-URI `image/svg+xml` of the Walk Studio **glyph only** (film-frame +
   coral click-cursor), `viewBox 0 0 84 84`, lifted verbatim from
   `branding/logo-walkstudio-light.svg` (`#FFF1EE` fill, `#F4C9BF` frame/notches,
   `#D6351C` cursor). No external/network asset.
3. **Header brand block** (`.bar-brand`, ~line 36): removed the old coral `.mark`
   "H" square + `.bar-name` "HERMES" + the `/` div between them, and inlined the
   FULL Walk Studio logo (glyph + "Walk" + mono "STUDIO" wordmark) as
   `<svg class="bar-logo" viewBox="0 0 540 120">`. Kept a `/` divider
   (`.bar-div`, `aria-hidden`) + the existing `.bar-sub` "PRODUCER CONSOLE"
   sub-label after the logo, matching the original type treatment (understated).
   - The source SVG used a `<defs><style>` block with `.wk`/`.st` classes; when
     inlined into the page those class names risk colliding with page CSS, so the
     two `<text>` elements carry **inline** `font-size`/`font-weight`/
     `letter-spacing`/`font-family`/`fill` attributes instead. Spacing matched:
     -0.04em→-2.1 on the 52px "Walk", 0.34em→5.1 on the 15px "STUDIO".
4. **`styles.css`** (~line 109): replaced the unused-now `.mark` rule with
   `.bar-logo { height: 36px; width: auto; display: block; }` (height-locked to
   the 54px bar row, width auto from the 4.5:1 viewBox so aspect ratio is
   preserved). `.bar-brand` gap nudged 10px→12px. `.bar-name`/`.bar-div`/
   `.bar-sub` rules retained (`.bar-name` is no longer referenced by markup but
   the rule is harmless).
