## B. Real default web fetcher (brand_extract.py)
`_live_webfetch` (now the DEFAULT fetcher in extract_brand): bounded stdlib
urllib GET (timeout 8s, 600KB cap, browser UA, follows redirects, blanket
try/except) -> `_parse_html_brand` parses:
  - name: og:site_name -> cleaned <title>
  - tagline: meta description -> og:description -> first <h1>
  - accent: <meta theme-color> hex (else none)
  - features: <h2>/<h3> + nav <a> + <li>, stop-worded, deduped, <=5, short
Returns strict-JSON the existing _parse_fetch_payload consumes. On ANY failure
returns "" -> graceful fallback (correct part-A name + clean LIGHT palette +
honest-empty copy). NEVER hangs, NEVER fabricates, NEVER returns dark generic.
Display name refined from og:site_name/<title> ONLY when it case-insensitively
contains the registrable label (nicer casing, no junk-title risk).
