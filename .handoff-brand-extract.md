## What it does
`python3 brand_extract.py --url <url> [--name <override>] --out <path>` turns a
company URL into a `brand_theme.json` the style-fill engine uses to re-skin a
curated template.

## Files
- `brand_extract.py` (new, stdlib-only; ~265 lines)
- `tests/test_brand_extract.py` (new, 15 tests, network-free via injected fetcher)
- `run_all_tests.sh` — added `python3 -m unittest tests.test_brand_extract` in 2b.

## brand_theme.json schema (the style-fill contract)
```
{name, host, tagline, palette:{bg, ink, accent, accent2, success},
 fonts:{display, mono}, wordmark_svg (inline SVG | null),
 features:[{title, sub}], copy:{hook, cta}}
```

## Reused vs added
- REUSED (no duplication): `remotion_codegen.palette_for(url)` (canonical brand
  resolver + BRAND_PALETTES + `_name`/`_host`), `_brand_name`/`_root_host`,
  `_DEFAULT_FONT`. Known brands (stripe/linear/notion/vercel) resolve straight
  from BRAND_PALETTES incl. their curated, hand-verified tagline.
- ADDED: a normalizer from the existing palette dict (bg/panel/accent/accent2/
  fg/dim/tagline/font) into the Phase-2 contract — `ink`=fg, `success`=accent2
  (or a calm green fallback), `fonts.mono` paired from a curated mono stack
  (no network font); a name-derived inline wordmark SVG; an injectable fetch
  seam (`fetcher(url, prompt) -> str`) + a defensive JSON parser.

## Honesty (the regressed past bug — do NOT reintroduce)
The old `_copy_from_brief` leaked hardcoded "Stripe" copy into every build.
Guards here:
1. Unknown brands get their REAL name + the generic `_default` palette + EMPTY
   tagline/hook + EMPTY features. Nothing is invented.
2. `copy.hook` MIRRORS the real tagline only; `copy.cta` is always the neutral,
   domain-agnostic "Get started" (never a leaked-brand imperative).
3. The fetch parser drops untrusted data: invalid hex -> dropped; a feature with
   no title -> dropped; malformed/raising fetch -> empty payload, never a crash.
4. Test `test_no_leaked_brand_strings_anywhere` asserts no
   stripe/linear/notion/vercel/operon strings appear in an unknown brand's theme.

## Live fetch seam (important)
WebFetch is an AGENT tool, not importable Python. The bare CLI uses
`_live_webfetch` which returns "" (so it stays honest: real name + generic
palette + empty copy). To enrich with a REAL tagline/accent/features, the agent
should call WebFetch with `brand_extract.FETCH_PROMPT`, then inject the result
via `extract_brand(url, fetcher=lambda u,p: <webfetch_answer>)`. The parser
already enforces honesty on whatever the fetch returns.

## One command to extract a real brand
```
python3 brand_extract.py --url https://stripe.com --out runs/<id>/brand_theme.json
```
