# Handoff: parallel walkthrough + failure isolation

## Goal
Fix run-loss when the slow/flaky `walkthrough` scene fails (run `build-replicate-a16f08`
died: walk-agent failed -> AdapterError -> serial loop aborted -> 2 later scenes never
ran, no video stitched).

Two changes:
- **A) Failure isolation (DEFAULT ON, the bug fix):** one scene's failure no longer
  kills the run. Diagnosable walk-agent errors. Status `completed_with_warnings`.
- **B) Parallel walkthrough (behind `HERMES_PARALLEL=1`, default off):** walkthrough
  walk-agent runs off-thread, removed from the critical path.

## Hard invariant (SACRED)
Budget GATE, `money.authorize()`, `write_active_budget`/webhook, ledger `spent`
accounting, and per-scene decision order MUST stay SERIAL + in scene order. Only slow
GENERATION may run off-thread. Money-shot (approve->approve->DECLINE) byte-for-byte.
