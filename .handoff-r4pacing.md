# R4-pacing handoff — staged headline reveal (D2 pacing)
_Written 2026-06-22. Status: COMPLETE. Tests green. tsc clean._

## What was done

**Problem:** HeroTitle / AppleHero / ExplainerCard rendered title text as a single static
block — no internal motion during the hold. D2 (pacing) scored 3.80, the only remaining
dimension below 4.0 and the R4 convergence blocker.

**Fix:** Added line-by-line staged reveal with two-tone active/pending treatment to the
three affected archetypes. Every multi-word headline now has internal motion across its
reveal window instead of a static hold.

## Files changed (studio/src/timeline/ only)

### motion.ts
Added two new helpers at the bottom of the file, before the "Act badge helpers" block:
- `splitToLines(text, maxCharsPerLine=22)`: splits a title string into 2-3 display lines
  using explicit `\n` first, then 50%-word-split heuristic. Short texts (≤3 words or
  ≤maxCharsPerLine chars) return as a single line.
- `stagedLine(frame, lineIndex, startFrame, stagger=16, dy=28, dur=18)`: per-line
  reveal returning `{opacity, transform, colorP}`. colorP 0→1 drives the two-tone
  color (0=pending=textDim, 1=active=text).

### archetypes/HeroTitle.tsx
- Imports: added `splitToLines`, `stagedLine` from motion.
- Moved `titleText` declaration before the staged-reveal setup so it's available for
  `splitToLines`.
- Title block replaced: single `<div>` → `<div wrapper (spring scale)>` containing a
  `.map(titleLines)` where each line gets its own `stagedLine` call. Each line's color
  is `theme.text` (arrived) or `theme.textDim` (pending). punchWord accent applies only
  on the line that contains it.
- Removed the now-unused `titleY` variable; accent underline no longer uses it.

### archetypes/ExplainerCard.tsx
- Imports: added `splitToLines`, `stagedLine`.
- Title block replaced: single `<div>` → wrapper div with `opacity/translateY` from a
  spring (kinetic-light damping 16) containing a `.map(titleLines)` where each line gets
  `stagedLine`. Pending lines dim to `theme.textDim`.
- Underline now fires after the LAST line settles: `lastLineStart + 12..+34` instead of
  `titleAt + 12..+34`, so the blue sweep lands after all lines are in.

### archetypes/AppleHero.tsx
- Imports: added `splitToLines` (stagedLine not needed — uses appleMaskRise per line).
- Removed the shared `const title = appleMaskRise(...)` and `const {pre,hit,post}`.
- Title block replaced: `<div column flex>` with `.map(titleLines)` where each line's
  `lineStart = titleAt + li * TITLE_STAGGER` drives its own `appleMaskRise`. Two-tone
  via `m.p > 0.5` → `theme.text` : `theme.textDim`. punchWord per-line splitPunch.
- Accent underline: now fires at `punchAt` (after titleAt + last line stagger), using
  `interpolate(frame, [punchAt, punchAt+16], [0,1], EASE_OUT_QUART)` for opacity.
