## Endpoint
`GET /api/analytics` -> `200 application/json` = `analytics.summarize()`.
On any internal error: `500 {"error": "analytics failed: <msg>"}` (server never crashes;
import of analytics is lazy inside the handler). No params, no auth, read-only.

## JSON contract — `{ "builds": [...], "totals": {...} }`

### `builds[]` — ONE row per readable ledger, newest-first (created_at then run_id, reversed)
Includes ALL runs (delivered/complete/failed/running) so the tab can show full history.
| field | type | meaning |
|---|---|---|
| `run_id` | string | run id / folder name |
| `brand` | string\|null | `job.company_url` (the client URL; use as the "brand" label) |
| `created_at` | string\|null | ISO ts; null for many real builds (sort already handled server-side) |
| `mode` | `"mock"`\|`"real"`\|null | mock = $0 test, real = paid pipeline |
| `price_charged_cents` | int\|null | charged price (cents). pnl.price_cents, else pricing.suggested_price_cents, else null |
| `cogs_spent_cents` | int | actual spend (cents), always a clean int (0 if unknown) |
| `gross_profit_cents` | int\|null | price - cogs; null only when price is null |
| `margin` | float\|null | (price-cogs)/price rounded to 4dp; null when price is 0/null |
| `declines` | array | `[{ "scene": <scene_id str>, "saved_cents": <int> }]` — money the budget gate saved per declined scene (empty if none) |
| `overage_saved_cents` | int | sum of saved_cents on this build (== pnl.overage_avoided_cents) |
| `status` | string\|null | `delivered`\|`complete`\|`completed_with_warnings`\|`failed`\|`running` |

NOTE on `declines[]`: key is **`scene`** (the scene id, e.g. `"hero-still"` or
`"__voiceover__"`) and **`saved_cents`** — this is RENAMED from the ledger's native
`pnl.declines[] = {id, would_have_cost_cents}`. Match these names exactly in the UI.

### `totals{}` — rollup
| field | type | meaning |
|---|---|---|
| `builds` | int | count of ALL builds (every readable ledger) |
| `real_builds` | int | count of REAL builds = terminal (not running/failed) AND priced (price != null) |
| `total_revenue_cents` | int | sum of price_charged_cents over REAL builds only |
| `total_cogs_cents` | int | sum of cogs_spent_cents over REAL builds only |
| `total_gross_profit_cents` | int | total_revenue - total_cogs |
| `avg_margin` | float\|null | simple mean of REAL-build margins, 4dp; null if no real builds |
| `total_overage_saved_cents` | int | sum of overage_saved_cents over ALL builds (the money-shot headline) |
| `total_declines` | int | count of decline events across ALL builds |

Revenue/COGS/margin = REAL builds only (honest money). Overage + declines = ALL builds
(so a cut on a failed/running run still shows the gate working). Render cents/100 for $.

## Legacy / in-flight ledger handling (does NOT crash)
Some ledgers predate the `pnl`/`premium`/`quality` blocks, or are `failed`/`running`
before the P&L was written. For any ledger missing `pnl`, `analytics._reconstruct_pnl`
rebuilds the numbers from `scenes[]` + `voiceover` (sum `spent_cents` for COGS, sum
`would_have_cost_cents` on `decision=="decline"` for overage) and takes price from
`pricing.suggested_price_cents`. Missing `premium`/`quality`/`pnl` blocks are simply
absent — nothing references them directly. Torn/unparseable ledger.json files are
skipped. A run never priced => `price_charged_cents: null` and is EXCLUDED from totals.
