## THE PIPELINE (what a build does, end to end)
`build_runner.py` (dashboard `/api/build` or run directly) →
1. **`brand_extract.extract_brand(url)`** — curated `branding/<host>-brand-theme.json` fixture else live web-fetch; **robust accent for ANY brand** (theme-color → dominant page color → deterministic per-domain hash; never the old `#2563EB`-for-all); UI/nav-label filter on facts; public-suffix-aware name; `_WELL_KNOWN_NAMES` ("Theverge"→"The Verge").
2. **planner (Nemotron via OpenRouter)** — `plan_job` + `validate_planner.SYSTEM_PROMPT`; **genre-aware grounding** (dev-tool/fintech/marketplace/ecommerce/media/retail, not SaaS-only), a COMPANY-FACTS world-knowledge block for thin/bot-blocked scrapes, stage-direction sanitizer. Deterministic grounded **template fallback** if the LLM call fails (the brain key isn't always in the build env, so the offline path is grounded too).
3. **`align_vo.py`** (edge-tts, `$0`) → **`build_timeline.py`** (honors target duration) → **`style_fill.py`** (fills `orinovate-kinetic-light`; entity-decode, clause-complete headlines, reject nav-label/section/stage-direction titles).
4. **`capture_screenshots.py`** — Playwright (`.venv-capture`) real screenshots of the emphasized pages (SPA hydration gate, bot handling); bot-walled sites → **populated on-brand-accent mocks** (`adapters._brand_mock_png`).
5. **walk-agent** — `walk_native.py` (real) / cached / synth (mock).
6. **studio Remotion `<Timeline>`** → `final.mp4` (`remotion render src/index.ts Timeline <out> --codec=h264 --concurrency=8 --props=<abs props.json>`, cwd=studio).
7. **pricing + `orchestrator.py` budget-gate + Stripe** → `ledger.json` (status=delivered, P&L). **Pricing is dynamic-banded** (Standard ~$5-10, Premium ~$15-25, quoted after planning, factors token cost — see `pricing.py`/`build_runner._build_quote`; verify, it was migrated from fixed tiers mid-project).
