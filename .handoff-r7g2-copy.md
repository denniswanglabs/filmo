## Changes made to `style_fill.py`

### 1. `_ends_mid_word(text)` — new helper (added after `_is_truncated_meta`)
Detects when a string ends on a short alphabetic fragment (1-4 chars, not in `_KNOWN_SHORT_WORDS` allowlist, with ≥3 words of sentence context). Called by `_is_truncated_meta` so "...all in Webf" triggers the truncated-meta guard and gets rejected by `_clean_complete_headline`.

Also added `_KNOWN_SHORT_WORDS` frozenset: short complete words/acronyms that are valid final tokens (ai, ml, on, app, etc.) so they are NOT flagged as mid-word fragments.

### 2. `_is_ui_nav_label(text)` — new helper
Rejects UI/nav-label chrome copy that leaks from JS homepages:
- Any string containing " · " (nav-tab bullet join) → always rejected
- Strings containing known UI phrases: "added to cart", "new arrivals", "become a host", "homes on", "what's happening", "sign in", "log in", etc.

### 3. `_is_prompt_artifact(text)` — new helper
Rejects instruction/stage-direction fragments that leaked from LLM prompts:
- Strings starting with: "show call-to-action:", "display the ", "present the ", "animate ", "scene:", "title:", "cta:", "headline:", etc.
- Strings containing: "call-to-action:", "call to action:"

### 4. `_is_fragment_subtitle` — extended
Added to the rejection set:
- Calls `_is_ui_nav_label(t)` → reject
- Calls `_is_prompt_artifact(t)` → reject
- Extended `_FRAGMENT_TERMINALS` to include relative/subordinating words: "who", "that", "which", "where", "when", "while", "than" (mid-relative-clause chop guard)

### 5. `_DANGLING_WORDS` — extended
Added "who", "that", "which", "where", "when", "while", "than" so `_title_from_text` strips dangling relative/conjunction tails.

### 6. `_title_from_text` — fixed sub-limit dangling-word stripping
Previously only stripped dangling words AFTER truncation (len > limit). Now strips dangling words ALWAYS (both after truncation AND on sub-limit strings that naturally end on "who"/"that"/etc.). Fixes "brands for men who" → "brands for men".

### 7. `_clean_complete_headline` — extended
Added early-exit checks for `_is_ui_nav_label` and `_is_prompt_artifact` before any other processing.

### 8. `_brand_fallback_title` — docstring updated
Documents the new rejection rules.

### 9. `_distinct_tagline` — extended
The tagline candidate now also rejects via `_is_ui_nav_label` and `_is_prompt_artifact` in addition to `_is_fragment_subtitle`.

### 10. `_shape_hero` — sanitizes explicit plan copy
The `d.get("title")` value from the plan (which could carry contaminated copy) is now checked via `_is_ui_nav_label` + `_is_prompt_artifact` before use, in both the closing and opening title paths.
