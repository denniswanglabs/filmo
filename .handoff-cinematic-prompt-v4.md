## The v4 refinement (establish track only)

### 1. Finer hue map — new `_color_hue_name(deg)` + specific `_color_name(hex)`
Split the coarse 12-name wheel into a FINER wheel with intermediate green prototypes
so an in-between hue anchors on the NEAREST specific prototype, not the nearest coarse
bucket. New green-axis bands (the fix zone):
- `64–78°` → **yellow-green**   (e.g. `#A4D233` 77° NVIDIA secondary)
- `78–88°` → **lime**           (`#76B900` 82° NVIDIA, `#86BF1D` 81° Shopify-2)
- `88–106°` → **olive green**    ← `#5E8E3E` 96.0° / `#468E15` 95.7° Shopify (THE FIX)
- `106–135°` → **green**         (`#00C805` 121° Robinhood)
- `135–158°` → **emerald green** (`#1DB954` 141° Spotify, `#7CFFB2` 145° generic)
- `158–178°` → **teal** (`#00B894` 168°) · `178–200` cyan · then blue/indigo/purple/...
Boundaries placed so both Shopify greens (raw 96.0° / sat 95.7°) sit inside the
olive-green band and the iter-5 saturation boost never crosses a band edge for any
documented brand accent (base-hue is hue-preserving).

Plus **saturation/value QUALIFIERS** (`_color_name`): a dark hue → "dark X"; a muted
mid-tone (sat≤.50, val≤.72) → "muted X"; a vivid bright prototype gets NO qualifier
(already unambiguous). And a `_DARK_MUTED_SPECIFIC` table maps a dark+muted purple to
its precise prototype: `#4A154B` (Slack aubergine, dark muted) → **"aubergine"**.

### 2. Name/hex re-balance — `_color_dominance(name, hexes)`
v3 repeated the BARE name (e.g. "green") ~5× and the hex 1× → name out-voted hex. v4:
- The grade label leads with the specific name: `"olive green-dominant color grade"`.
- BOTH color anchors now PAIR the name with the hex — `"olive green (#468E15)"` —
  instead of a bare repeated word: `"bathed in olive green (#468E15) light"` and
  `"olive green (#468E15) as the single dominant color of the whole frame"`.
- Middle clause uses neutral "its glow tinting the volumetric haze, the reflections
  and the background" (no extra bare-name repeat). Net for Shopify: name 3× (label +
  2 anchors), hex 2× (both anchors) — vs v3's 5×/1×. No bare "green" token ever stands
  alone (every "green" is preceded by "olive ").
- Unnameable hue (grey/garbage) → "brand accent (#hex)" fallback, still whole-frame.
