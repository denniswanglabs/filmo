## WHAT CHANGED

### 1. First-run landing rebuilt into a real onboarding surface (`.stage-empty`)
The old empty state was one headline + one sentence. It is now a top-anchored,
scrollable landing that teaches the product and points at the next click:

- **Eyebrow** "AUTONOMOUS VIDEO PRODUCER" (drawn coral ticks each side — no emoji) —
  instant category line above the hero.
- **Hero** (large serif, kept the word-by-word blur-rise build, accent lands last):
  "Give it a URL. It plans, prices, produces, and **ships a video.**" — names the
  whole loop in one line; coral resolves on the payoff clause.
- **Subhead**: "A 30-second promo **plus a product walkthrough**, made end to end by
  one agent — no editor, no timeline, no human in the loop." States the deliverable.
- **HOW IT WORKS — a bespoke 4-beat pipeline strip** (`<ol class="how">`): four
  film-slate badges **H1 Plans → H2 Prices → H3 Produces → H4 Ships**, each with a
  one-line description ("reads the site, writes a script & shot list" / "quotes the
  job & sets a hard budget" / "shoots every scene, auto-cuts over budget" /
  "stitches the final cut, ready to download"). Connected by **one continuous coral
  thread** that draws itself L→R on load, beats rising in sequence behind it. This
  is the "plans → prices → produces → ships" concise explainer the brief asked for.
- **Two CTAs**: primary coral **"Paste a URL to start"** (`#hero-start` → focuses the
  URL input + a one-shot coral ring nudge so the eye lands on it) and secondary
  **"See a finished example"** (`#hero-sample`, `data-run="demo-1-approve"` →
  `selectRun()` opens the real delivered Stripe run with video + download). One-click
  way to see the payoff before committing — exactly the brief's ask.
- **Footnote**: "Or open any build in the list to see exactly how the agent priced
  and produced it."

### 2. Clearer input affordances in the NEW BUILD bar (`index.html`)
- Field **labels** ("PASTE A COMPANY URL", "WHAT SHOULD THE VIDEO SHOW?", "PACING")
  so each input is self-explanatory without a tooltip.
- Example **placeholders**: `e.g. stripe.com` (was "company URL…") and
  `e.g. how to find your API keys` (was "goal (optional)…" — the goal is load-bearing
  for the walkthrough, so it's reframed as "what should the video show?", not "optional").
- The three **pace options now have explanatory titles** (Snappy = "Quick cuts —
  punchy, social-ready", Standard = "Balanced pacing — the default", Cinematic =
  "Slower, held shots — premium feel"). Standard stays the default `is-on`.
- Build button gains a forward arrow (`i-arrow`) that nudges on hover; hidden while
  disabled mid-build.

### 3. Distinctiveness ("less generic-AI"), on the light/coral base
- The **H1–H4 take-slate badges** (mono H + coral step number + ghosted line-icon)
  echo the HERMES "H" wordmark and the film-production vocabulary — a bespoke detail,
  not a stock feature grid.
- The **single coral pipeline thread** binding the four beats is the memorable detail:
  it says "one continuous agent run" at a glance.
- Eyebrow with drawn coral end-ticks, type-character via the existing serif hero at a
  larger `clamp()` scale, focus ring + box-shadow glow on inputs, arrow micro-motion.
- New SVG icons added to the sprite (no emoji): `i-plan, i-coin, i-film, i-ship,
  i-arrow, i-spark` — all stroke-only line icons matching the existing set.

### 4. JS wiring (`app.js`)
- `focusBuildUrl()` — focuses `#build-url` + one-shot `.nudge` ring (reflow-restarted,
  no setInterval).
- `replayLandingMotion()` — toggles `.is-live` on `#stage-empty` with a reflow so the
  how-it-works strip + CTA entrance **replays every time the landing is shown** (first
  paint AND on return after deleting the last build), not just once on element create.
  Called from `init()` and `showEmpty()`.
- `#hero-start` / `#hero-sample` listeners wired in `init()`.

click* within the first glance, and can watch a real delivered run in one click.
