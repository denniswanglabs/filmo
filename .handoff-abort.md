# Handoff — ABORT button (stop an in-progress build)

Scope: dashboard only. Files edited:
- `dashboard/serve.py`
- `dashboard/app.js`
- `dashboard/styles.css`
Backups: `dashboard/<file>.pre-abort.bak` (kept).

## What changed

### serve.py
1. `import signal` and `import time` added.
2. `_api_build`: capture `proc = subprocess.Popen(...)` and write `str(proc.pid)`
   to `runs/<run_id>/build.pid` (best-effort). Because the build is spawned with
   `start_new_session=True`, that PID == the process-GROUP id.
3. New `POST /api/abort` (`_api_abort`), wired in `do_POST`:
   - Body `{"id": run_id}`; id sanitized via `safe_run_dir` (bad id -> 400,
     missing run dir -> 404).
   - Reads `runs/<id>/build.pid`, `os.killpg(pgid, SIGTERM)`, polls up to ~2s
     (`os.killpg(pgid, 0)` liveness probe), then `SIGKILL` if still alive.
   - Always sets `runs/<id>/ledger.json` `status="aborted"` + `"aborted_by":"user"`
     (preserves all other fields) so the run leaves `/api/active` and the UI shows
     stopped.
   - Idempotent: missing/garbage build.pid or already-dead group still marks the
     ledger aborted and returns `{ok:true}`.

### app.js
- `liveHeader(l)`: added a `#live-stop` "Stop build" button (inline stop-square
  SVG, no emoji) into the `.live-top` row. liveHeader renders for EVERY in-progress
  phase (planning/pricing/awaiting_payment/producing/voiceover/stitching), so the
  button is present throughout the build and absent on delivered/failed/aborted
  (those render other views).
- `wireLiveStop(runId)`: new; called at the end of BOTH `renderLive` branches
  (awaiting_payment + production). On click -> `POST /api/abort {id}` -> stops the
  poll loop + live-walk, clears timers, and paints `buildStopped(runId)`.
- `buildStopped(runId)`: new "Build stopped" view (STOPPED pill + explanation +
  "New build" button wired to `newBuild`).
- `beginPoll` tick: also handles `status === "aborted"` out-of-band (stop polling,
  show stopped view) so an abort from another tab doesn't spin forever.

### styles.css
- `.live-stop` (neutral/destructive secondary using `--bg-2`/`--line-2`, hover ->
  `--neg`/`--neg-2`; NOT coral), `.live-pill.stopped`, `.bs-body/.bs-msg/.bs-actions/.bs-new`.
- `.live-goal` now `flex: 1 1 auto` so the stop button right-aligns via `margin-left:auto`.
