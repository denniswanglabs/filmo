# Handoff — PREMIUM reliably yields cinematic (was: live planner under-used it)

Owner: premium-cinematic subagent, 2026-06-21.

## Bug fixed
The planner was quality-aware (STANDARD correctly = Remotion-only, 0 cinematic),
but PREMIUM only *allowed* cinematic, it did not *require* it. The LIVE Nemotron
planner therefore drifted to all-motion_graphic for premium -> Premium looked
identical to Standard, with no Higgsfield footage. Now PREMIUM is a REQUIREMENT:
>= 2 cinematic (a seedance_2_0 establishing shot + a gpt_image_2/seedance hero
shot), enforced in the prompt AND with a deterministic backstop.

## Changes
1. PROMPT (root-cause fix):
   - `validate_planner.SYSTEM_PROMPT`: QUALITY section + structure rule 2 rewritten
     so PREMIUM "MUST include AT LEAST 2 cinematic" (establishing seedance_2_0 +
     hero gpt_image_2/seedance_2_0). Zero cinematic = INVALID.
   - `plan_job._QUALITY_PROMPT["premium"]`: was `None` (injected nothing). Now a
     hard-requirement block appended AFTER the style guidance, mirroring the system
     prompt's premium markers.
   - `planner-prompt.md`: doc kept in sync (Prompt approach, QUALITY rules,
     structure rule 2, post-parse assertion all updated to ">= 2 (2-4) cinematic").

2. SCHEMA CHECK:
   - `validate_planner.schema_check(plan, dur, quality="premium")` (premium is the
     DEFAULT, so main() unchanged): asserts n_cine >= 2 (msg names the establishing
     + hero requirement), n_cine <= 4 upper bound kept. STANDARD branch unchanged
     (0 cinematic, >=1 motion_graphic).

3. BACKSTOP (defense-in-depth, deterministic):
   - `plan_job._enforce_quality(plan, quality)` extended. STANDARD path unchanged
     (cinematic/walkthrough -> motion_graphic, model null). PREMIUM path NEW: if the
     model returns < 2 cinematic, upgrade non-title feature beats (prefer
     motion_graphic, then any non-title) to cinematic, assigning seedance_2_0 then
     gpt_image_2; preserves ids/durations/briefs/beats; normalizes stray walkthrough
     -> cinematic and fixes invalid cinematic.model.
   - `plan_job.plan_job`: after the backstop, if PREMIUM STILL has < 2 cinematic
     (too few scenes to upgrade), falls back to the deterministic premium template
     (which always has cinematic). Stale "No-op for premium" comment fixed.

4. main() repair (validate_planner): main() validates the PREMIUM path, so it now
   appends `PREMIUM_QUALITY_GUIDANCE` (mirrors _QUALITY_PROMPT["premium"]) to the
   system prompt — without it the standalone live call drifted to 0 cinematic.
   Also fixed a pre-existing crash: word-count read `voiceover["script"]` (retired
   for per-scene `beats`) -> KeyError; now counts `beats` text.
