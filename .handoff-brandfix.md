# Brandfix handoff — overlay path was rendering OPERON on non-Operon clients

## Bug
`adapters.generate_overlay` (the title/motion_graphic path through the sibling
`motion-graphics-kit` Remotion project) was never brand-threaded. It passed the
raw brief as `title`, hardcoded `accent:"#7CFFB2"` (lime), and passed no
kicker/subtitle — so the kit fell back to leftover Operon defaults
("OPERON SOLUTIONS" / "AI that reads your plant diagrams"). A Stripe-docs video
rendered Operon branding. Evidence: runs/demo-parallel-stripe/_frames/final_title.png

## Fix (3 files + 3 .bak backups)
1. orchestrator.py (~line 363): `generate_overlay(scene, out, mode)` →
   added `company_url=job.get("company_url")`. (Only call site; studio path
   already gets the palette.)
2. adapters.py `generate_overlay`: added `company_url=None` param. Resolves
   `palette = remotion_codegen.palette_for(company_url)` and parses copy via
   `remotion_codegen._copy_from_brief(scene, brief, palette)` →
   `(title, subtitle, kicker, badge)`. Passes EXPLICIT props:
   {variant, kicker, title, subtitle, badge, accent: palette["accent"],
    accent2: palette.get("accent2"), fg: palette["fg"], bg: palette["bg"],
    solidBg: True}. Mock path + kit-missing fallback unchanged.
3. motion-graphics-kit/src/Overlay.tsx: neutralized `overlayDefaults`
   (kicker "OPERON SOLUTIONS"→"Studio", title "P&ID Recognition"→"Title",
   subtitle "AI that reads your plant diagrams"→""). Animation/layout untouched.
