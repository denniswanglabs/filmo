## What changed

### pricing.json (v4 fixed_tier -> v5 dynamic_banded)
- model: "fixed_tier" -> "dynamic_banded".
- Added per-tier `price_band_cents`: standard {min:500,max:1000}, premium {min:1500,max:2500}.
- Kept `tier_price_cents` (999/1999) as back-compat fallback.
- Added `token_rate_cents_per_1k` table (cents per 1k tokens, input/output, per brain):
  super-free 0/0; super-paid 0.009/0.045; ultra-paid 0.05/0.22 (derived from brain.py
  per-1M rates /1000).

### pricing.py
- New helpers: `price_band_cents()`, `_token_rate()`, `estimate_planner_tokens()`,
  `token_cost_cents()`, `_duration_blocks()`, `_dynamic_line_items()`.
- `price_for_plan(plan_cogs_cents, quality, pricing, signals=None)`:
  - WITHOUT signals -> single base line at band MIN (existing callers safe).
  - WITH signals -> storyboard-derived itemized price, CLAMPED to tier band.
  - Returns {model:"dynamic_banded", quality, line_items:[{key,label,amount_cents}],
    band:{min_cents,max_cents}, base_price_cents, plan_cogs_cents, token_cost_cents,
    raw_price_cents, total_price_cents, total_cogs_cents, margin}.
- Formulas (constants in code, band clamp from json):
  - standard = 500 + 50*max(0,scenes-3) + 50*ceil(max(0,dur-20)/10) + token_cost; clamp[500,1000]
  - premium  = 1500 + 150*cinematic + 100*ceil(max(0,dur-20)/10) + 300*has_vo + token_cost; clamp[1500,2500]
- `price_for_selection` / `price_selection` gained optional signals (default None -> band floor).

### producer.py (_apply_premium_menu path, WS_PREMIUM_MENU=1)
- Renamed `_quality_resolved_cogs` -> `_quality_resolved_media_cogs` (media COGS only).
- New `_storyboard_signals(result, plan)` -> {scenes, cinematic_count, duration_s,
  uses_vo, vo_chars, brain, walkthrough_steps}.
- `_apply_premium_menu`: computes token_cost via pricing.token_cost_cents, FOLDS it into
  total_cogs = media_cogs + token_cost (the SACRED budget = COGS, not price), passes
  signals to price_for_plan, asserts price >= total_cogs (logs `price_below_cogs_warning`
  if violated), sets production_budget_cents = total_cogs, suggested_price_cents =
  menu.total_price_cents. Adds result["signals"], result["token_cost_cents"].

### build_runner.py
- New `_build_quote(est, currency)` -> exact ledger.quote schema from est.menu + est.signals.
- In run(): writes `led.data["quote"]`, pins price_cents = quote.price_cents so
