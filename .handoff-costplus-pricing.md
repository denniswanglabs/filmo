# Handoff — COST-PLUS PRICING (the contract for the dashboard agent)

_Written 2026-06-21. Owner: cost-plus-pricing subagent. REPLACES the tier+booster
model from `.handoff-pricing-foundation.md` / `.handoff-premium-produce.md`. Read
this instead of those for pricing; the dashboard pricing UI consumes THIS contract._

## TL;DR
The Starter/Pro/Studio tiers + 6 boosters are GONE. Pricing is now COST-PLUS:
the customer price = the agent's REAL production COGS (its scene plan) x a markup,
with a price floor, rounded to a clean increment, PLUS exactly ONE customer add-on:
`premium_vo` (a flat surcharge for a premium natural voiceover via an ElevenLabs
STOCK voice — NOT a clone, so NO consent). Still gated behind env
`WS_PREMIUM_MENU=1` (default OFF = pre-premium behavior byte-identical). Money is
integer CENTS (USD). The SACRED budget-gate / Stripe authorize sequence is
UNTOUCHED — only the price/budget NUMBERS fed in changed.

The DASHBOARD owns the pricing UI (this agent did NOT touch `dashboard/*`).

## Files edited (each has a `*.pre-costplus.bak`)
- `pricing.json` — source of truth for the cost-plus numbers + the one add-on.
- `pricing.py` — `price_for_plan()`, `price_for_selection()`, `base_price_for_cogs()`,

  (`ELEVENLABS_STOCK_VOICE_IDS`); no clone path.

## CONTRACT 1 — pricing.json shape + numbers
```json
{
  "version": 2,
  "model": "cost_plus",
  "currency": "usd",
  "markup": 6.0,
  "price_floor_cents": 500,
  "round_to_cents": 50,
  "addons": {
    "premium_vo": { "label": "Premium voiceover", "price_cents": 300, "cogs_cents": 20 }
  }
}
```
All numbers tunable. NO `tiers`, NO `boosters` keys anymore.

## CONTRACT 2 — the math
```
base_price_cents  = max(price_floor_cents, round_to_nearest(plan_cogs_cents * markup, round_to_cents))
total_price_cents = base_price_cents + (premium_vo ? addons.premium_vo.price_cents : 0)
total_cogs_cents  = plan_cogs_cents  + (premium_vo ? addons.premium_vo.cogs_cents  : 0)
```
`plan_cogs_cents` is the producer's per-scene + VO COGS rollup (`total_cogs_cents`
from the estimate). `round_to_nearest` is half-up on the 50c increment.

## CONTRACT 3 — `price_for_plan(plan_cogs_cents, addons={"premium_vo":bool})` output
```json
{
  "model": "cost_plus",
  "line_items": [
    {"key":"video_production","label":"Video production","qty":1,
     "unit_price_cents":600,"unit_cogs_cents":100,"price_cents":600,"cogs_cents":100},
    {"key":"premium_vo","label":"Premium voiceover","qty":1,
     "unit_price_cents":300,"unit_cogs_cents":20,"price_cents":300,"cogs_cents":20}
  ],
  "base_price_cents": 600,
  "plan_cogs_cents": 100,
  "total_price_cents": 900,
  "total_cogs_cents": 120,
  "margin": 0.8667
}
```
- `line_items[0]` is ALWAYS the "Video production" line (the cost-plus base).
- `line_items[1]` (key `premium_vo`, label "Premium voiceover") is present ONLY
  when premium_vo is true.
- STABLE labels: `"Video production"`, `"Premium voiceover"`.
- `margin = (total_price - total_cogs) / total_price` (0.0 when price == 0).
- Raises `pricing.PricingError` only on a non-integer `plan_cogs_cents`.
  NO consent exceptions in the active flow.

Helpers the dashboard may use:
- `pricing.base_price_for_cogs(plan_cogs_cents)` -> the production-only base price.
- `pricing.price_for_selection(selection, plan_cogs_cents)` -> same as price_for_plan
  but takes a `selection` (reads its `premium_vo` toggle).
- `pricing.addons_from_selection(selection)` -> `{"premium_vo": bool}` (also maps a
  legacy `founder_voice` booster -> premium_vo for old plans).
- `pricing.default_selection()` -> `{"options": {"premium_vo": false}}`.

## CONTRACT 4 — the `selection` object (shared by plan_schema + dashboard)
```json
{ "options": { "premium_vo": false } }
```
- The ONLY field is `options.premium_vo` (bool). No tier, no boosters.
- A plan may carry `selection` as an optional FOURTH top-level key
  (`job/scenes/voiceover/selection`). Plans WITHOUT it still validate.
- OLD selections (tier + boosters[] + options.languages/.../.consent) still PARSE
  (validate_selection tolerates the retired fields; downstream ignores them).

## CONTRACT 5 — producer.py integration (what the gate sees)
`producer.cmd_estimate(plan)` adds these keys ONLY when `WS_PREMIUM_MENU=1`:
- `pricing_mode`: `"cost_plus"`
- `selection`: the resolved selection (plan's, or `default_selection()`)
- `menu`: the full `price_for_plan()` output (Contract 3)
- `menu_total_cogs_cents`
- OVERRIDES: `production_budget_cents <- menu.total_cogs_cents` (locked spend
  ceiling = plan COGS + premium_vo cogs); `suggested_price_cents <- menu.total_price_cents`
  (the Stripe Checkout amount).
UNCHANGED: per-scene `est_cost_cents`, `voiceover`, the per-scene `total_cogs_cents`
report, and the gate / Stripe authorize paths. OFF path byte-identical (verified
via diff on sample-plan.json + example-plan.json).

## CONTRACT 6 — premium_vo behavior (how the add-on actually produces)
- `premium_vo` = a premium NATURAL voiceover via an ElevenLabs STOCK library voice.
  STOCK voices are pre-made, NOT clones -> **NO consent required, no attestation
  form, no owner field.**
- Real ElevenLabs synth fires ONLY on `--mode real` (with `--vo elevenlabs`); in
  mock (the $0 default) it logs the upgrade and falls back to free edge-tts ($0).
- Recorded at `led.data["voiceover"]["premium_vo"] =
  {requested, engine, voice_type:"stock", consent_required:false[, reason]}`.
- No consent UI anywhere. (The retired voice-clone consent guardrail —
  `validate_consent`, the public-figure denylist — is still IN pricing.py for
  back-compat but is NEVER called by the active flow. Do NOT re-surface cloning.)

## What the dashboard should render
- The cost-plus quote from `producer`'s `menu` block (or call `price_for_plan`):
  the "Video production" line (price + the real COGS that drove it) and, if bought,
  the "Premium voiceover" +$3 line, plus the total + margin.
- One toggle: **Premium voiceover (+$3)** -> sets `selection.options.premium_vo`.
- The ledger itemization lives at `led.data["premium"]["ledger"]`
  (`line_items` / `total_price_cents` / `total_cogs_cents` / `margin`), which
  MATCHES `price_for_plan()` exactly (asserted by TestLedgerMatchesCostPlus).
- DROP from the UI: tier picker, all 6 boosters, the consent attestation form.
