- top: `import shutil`; `BRANDING` const; `VO_ENGINE_ENV="WS_VO_ENGINE"`,

- NEW `_run_vo_engine(plan, run_id, url, run_dir)` — writes plan.json + brand_theme,
  calls `style_fill.run_pipeline(plan_path, brand_path, VO_ENGINE_STYLE, run_dir,
  fps=30, do_align=True, do_render=False)` ($0: edge-tts + local whisper-cli), then
  `remotion render src/index.ts Timeline <run>/final.mp4 --concurrency=8
  --props=props.json`. Replaces the run's final.mp4 with the never-blank picture.
  Returns final path or None.
- `run()` — AFTER `orchestrator.orchestrate(...)` returns (so the SACRED budget
  gate + Stripe authorize + ledger/P&L have ALREADY run UNCHANGED), if
  `vo_engine_enabled()`: call `_run_vo_engine`, log a ledger event, write ledger.
  Wrapped in try/except so an engine failure NEVER fails an already-delivered run
  (keeps the legacy picture). orchestrator.py is NOT touched — money path intact.

WHY this shape: the diagnosis named two integration points (build_runner ~L137 and
orchestrator produce/stitch). Touching orchestrator's produce loop risks the SACRED
money sequence; instead the engine runs AFTER orchestrate and only overwrites the
PICTURE (final.mp4 — the exact path the dashboard already serves). Non-destructive,
flag-gated, legacy stays green.
