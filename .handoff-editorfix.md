## Fix 1 (PRIORITY) — play/scrub bar hidden behind timeline on load  [DONE]
Root cause: the preview stage `<section>` used `justifyContent:center` and held the
pills row + 16:9 canvas + PlayerControls in ONE inner column. The Player had only
`width:100%`, so the canvas grew to its full 16:9 height regardless of available
space. At a normal window the canvas+pills+controls were taller than the section's
flex-shrunk height; centered overflow bled the bottom (the controls) DOWN under the
bottom timeline `<section>` (which has its own bg + zIndex:5), covering the play bar.
Fix (App.jsx):
- `<main>` column: added `minHeight:0` so the column can shrink and children's
  `flex:1 + minHeight:0` take effect.
- inner preview column: `height:100%, minHeight:0`; pills row `flex:0 0 auto`.
- canvas card: now `flex:"1 1 auto", minHeight:0, width:auto, maxWidth:100%, display:flex`
  (shrinks to fill space left by pills + controls).
- stage (stageRef) box: `aspectRatio:"16/9", maxHeight:100%, maxWidth:100%, margin:auto`
  + Player `style` gained `height:100%` — so the dark video honors BOTH available
  width AND height, whichever binds. It can no longer overflow the column.
- controls row: `flex:0 0 auto` so it always keeps full height, never compressed/covered.
Result: preview shrinks first; play/scrub bar always fully visible at default window,
no manual resize. Short windows: preview shrinks further, controls+timeline stay put.

## Fix 3 — make screenshot HEADLINE editable  [DONE]
apple-screenshot renders `data.headline` with `data-field="headline"`
(studio/src/timeline/archetypes/AppleScreenshot.tsx:158).
- EditPanel.jsx FIELD_MAP: added `headline: { kind:"text", key:"headline" }`
  (auto-flows into exported TEXT_KEY_FOR_FIELD -> inline-edit key resolves).
- EditPanel.jsx TEXT_FIELDS: added `["headline","Headline"]` (labeled input renders).
- EditPanel.jsx ARCHETYPE_TEXT_FIELDS["apple-screenshot"]: `["headline","caption"]`
  so the row + click-select land even when key absent.
- SelectionOverlay.jsx INLINE_TEXT_FIELDS: added "headline" (double-click opens inline editor).
- SelectionOverlay.jsx FIELD_LABEL: added `headline:"Headline"` (tag above box).
