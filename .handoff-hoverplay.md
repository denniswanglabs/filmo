# Handoff: hover-to-play video previews on About lookbook

Status: COMPLETE + live-verified. 2026-06-21.

## Goal
On the Walk Studio dashboard About page lookbook (5 curated films), each card
shows its thumbnail (poster) first, plays the video on mouse hover, and
pauses + resets to the poster on mouse-leave — mirroring luceostudio.com.

## Mechanism mirrored from luceostudio.com
Source: `/Users/dennis/Desktop/Projects/Luceo/luceo-site/src/components/VideoCard.astro`
(and AlsoBuilding.astro — identical pattern). Exact behavior replicated:
- `<video muted loop playsinline preload="none" poster=...>` with NO `src` at render.
- `data-loop-src` holds the mp4 path.
- `pointerenter` handler: if `src` not yet set, set `video.src = data-loop-src`
  (lazy — preload="none" means it loads only on first hover), then `await video.play()`.
  On failure, `video.load()` + retry once (self-heal for transient load failures),
  else give up silently so the poster stays.
- `pointerleave` handler: `video.pause(); video.currentTime = 0` (poster returns).
- Gated on `matchMedia("(hover: hover) and (pointer: fine)")` so touch devices keep
  the static poster + tap-to-Watch behaviour.
- Poster→video crossfade via opacity (CSS), no flash, no layout shift.
- Click on the frame opens the full video → in the dashboard this is the YouTube
  WATCH link (luceo opens a lightbox; dashboard's existing affordance is YouTube,
  preserved as-is).
