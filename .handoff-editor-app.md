# Handoff — Experimental in-browser video editor

Status: BUILT + VERIFIED end-to-end (2026-06-22). Isolated experiment, additive only.

## What it is
A Vite + React page that loads a generated video's `props.json`, shows a LIVE
`@remotion/player` preview of the `Timeline` composition, lets a non-coder edit
text / lists / geometry / theme / timing, and re-exports the mp4 — NO LLM.

## Where it lives (all NEW files, nothing existing modified)
- `studio/editor/`  (self-contained; has its OWN node_modules with vite 5.4.21 + @vitejs/plugin-react 4.7.0)
  - `package.json`        — `npm run editor` -> `vite --port 3040`
  - `vite.config.js`      — aliases react/react-dom/remotion/@remotion/player to the studio's
                            symlinked node_modules (ONE React instance); `publicDir` = studio/public
                            so Remotion `staticFile()` assets (audio/screenshots/mp4) resolve live;
                            mounts the API middleware.
  - `server-api.js`       — Vite dev-middleware API: GET /api/runs, GET /api/props?id=,
                            POST /api/save, POST /api/render (streams render log).
  - `index.html`, `src/main.jsx`, `src/App.jsx`, `src/EditPanel.jsx`, `src/ui.jsx`
- `.claude/launch.json` (project) + `~/.claude/launch.json` (global) — added a `hermes-editor`
  config (port 3040). The preview tool reads the GLOBAL one. Both reverted by deleting that entry.

## How to launch
- `cd studio/editor && npm run editor`  -> http://127.0.0.1:3040
- or preview_start "hermes-editor"
- Does NOT touch the dashboard on :3030.

## What's editable (right panel, house-style, no emojis)
- Scene list (archetype + title) -> picks active scene.
- TEXT: title, kicker, subtitle, heading, headingAccent, punchWord, statement, caption,
  overlayTitle, footnote, product — renders an input per PRESENT field.
- LISTS: bullets[] (strings), cards[] (label/value/sub), entities[] (code/name/meta/type) — add/remove/edit.
- GEOMETRY sliders (headline feature) -> write scene.data.geo.<key> as numbers:
  hero-title/apple-hero: titleFontSize, subtitleFontSize, plateW, plateH
  apple-screenshot:      cardW, cardRadius, shotH
- TIMING: in_frame / out_frame number inputs.
- THEME (global): accent, bg, text, navy color inputs + wordmark + fontDisplay text.
- Every control mutates props state -> Player re-renders instantly.

- Preview shows a REAL video: apple-screenshot scene renders the captured Stripe homepage.
- Live text edit: title "Build internet businesses" -> "Edited live, no LLM" updated instantly.
- Live recolor: theme.accent #635BFF -> #FF1FA0; accent underline recolored instantly (whole-video).
- Live font-size: titleFontSize slider 132 -> 64; headline resized instantly.
  (Sibling geo agent HAS landed: HeroTitle + AppleScreenshot read `data.geo?.KEY ?? literal` with exactly these keys.)

- Re-export: ran the EXACT build_runner.py:293-295 command

  all 3 edits BAKED into the mp4.

## Rough edges
- Editor has its own node_modules (~58 pkgs) under studio/editor — clean to delete with the dir.
- Render took ~40s for this $0 timeline (screenshots+audio); premium/cinematic runs with video clips
  will take longer — the UI streams the remotion log but has no progress bar.
- File-input load (local props.json) works for preview but Save/render need a real run id (no run dir to write to).
- A dev hook exposes the Player ref on `window.__player` (for deterministic seeking during verify).
- structuredClone used per edit — fine for these small props; not optimized.

delete runs/r5-stripe/props.edited.json + runs/r5-stripe/edited.mp4 (experiment artifacts).
