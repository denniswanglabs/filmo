## Caveats (honest limits)
- **Social handles could not be confirmed.** Instagram and X both return HTTP 200 behind a login/redirect wall for *every* handle (real or fake), so curl can't distinguish taken vs open. All handle cells are **UNVERIFIED** — check `instagram.com/<name>` and `x.com/<name>` manually in a browser before locking a name. Don't trust any "available" claim here.
- **Trademark check** is a quick search-engine + Justia pass, not a full USPTO clearance. "Showrunner" is unambiguous (live reg. in-class). For Walkwright/Walkframe/Walkshow I found no US TM, but a formal TESS/attorney search is warranted before filing.
- `.com` "parked/for-sale" means *registered but not actively used* — the name itself is commercially clear even when the literal `.com` would need purchasing or an alternate TLD.

## Recommendation
Of names that are actually clear: **Walkwright is the safest strong pick** — zero software/video competitors, no US trademark, on-lineage with Walk Agent / Walk Ultra, and the only collisions are an out-of-class Indian apparel firm and a construction LLC. The one snag is `walkwright.com` is parked (not in use), so plan to either buy it or launch on `walkwright.app` / `walkwright.studio` / `getwalkwright.com`.

**Fallback:** Walkframe — coined, no market presence, likely TM-open; same Walk-lineage feel. Avoid Showrunner (burned) and Walk Studio (generic + taken). Confirm handles in-browser before final commit.
