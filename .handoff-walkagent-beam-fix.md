## Root cause (from WALKTHROUGH-INVOCATION-FIX.md)
Hermes runs the walk-agent with BEAM=1. BEAM scout/candidate tabs captured at
1280×720, but the Remotion `Explainer` card is 1440×900 with `objectFit:"cover"`
→ a 1280×720 frame is upscaled 1.25× to 1600px wide in a 1440px box → ~80px
clipped each side (Stripe wordmark left edge + account-nav right edge lost).
Fix: make scout/candidate/promoted-winner viewports 1440×900 so captures match
the card 1:1.

## The 4 edits (old → new)
1. **trySearchScout** (was ~line 1115):
   `await page.setViewportSize({ width: 1280, height: 720 });`
   → `await page.setViewportSize({ width: 1440, height: 900 });`
2. **executeCandidate** (was ~line 1226):
   `await page.setViewportSize({ width: 1280, height: 720 });`
   → `await page.setViewportSize({ width: 1440, height: 900 });`
3. **beam context creation** (was ~line 2883):
   `browser.newContext({ viewport: { width: 1280, height: 720 }, ignoreHTTPSErrors: true })`
   → `browser.newContext({ viewport: { width: 1440, height: 900 }, ignoreHTTPSErrors: true })`
4. **winner promotion** (after `leadPage = winnerPage;`, was ~line 3096) — ADDED:
   ```js
   // Keep post-promotion rounds at the card geometry (1440×900) so later BEAM
   // captures fill the Explainer card 1:1 and don't get cover-cropped.
   try { await leadPage.setViewportSize({ width: 1440, height: 900 }); } catch {}
   ```

Edits located by CONTENT (function names / surrounding lines), not blind line
numbers. Lines had not shifted materially from the doc.
