## Changes made

### `capture_screenshots.py` — two new helpers + grab() rewrite

**Added `_wait_for_spa_hydration(page, settle_ms)`** (lines ~167-212):
- After `page.goto`, waits for semantic selector `"h1, h2, main, article, nav a"` (attached, 10s timeout)
- Then `wait_for_load_state("networkidle", 10s)`
- Then `wait_for_timeout(settle_ms)` (default 1500ms)
- Called in ALL navigation paths inside `grab()`, replacing the old bare `wait_for_timeout(1200)` that fired before the JS bundle executed

**Added `_is_near_empty_png(path)`** (lines ~215-246):
- Uses `ffprobe … signalstats` to compute mean luma (YAVG) of the PNG
- Returns True if YAVG < 12.0 (near-black) OR YAVG > 247.0 (pure white)
- Threshold 12.0 specifically calibrated to catch Linear's WebGL-hero-only homepage (YAVG ~9.5)
- Falls back to False on any ffprobe error (never discards a good frame)

**Updated `grab()` near-empty retry (two-branch)**:
- After taking a screenshot, if `_is_near_empty_png` fires:
  - Branch A (body text > 500 chars): WebGL/Canvas hero — scroll 90% of viewport height down to expose real HTML content below the fold, then reshoot
  - Branch B (body text ≤ 500 chars): true hydration gap — settle 3s then reshoot
- Accepts the retry result regardless of its luminance

**Updated hydration gate in bot-block retry paths**:
- Apex retry page: `_wait_for_spa_hydration(fresh_apex, settle_ms=2000)` replaces bare `wait_for_timeout(2000)`
- Fresh-page retry: `_wait_for_spa_hydration(fresh, settle_ms=2000)` replaces bare `wait_for_timeout(2000)`

## Root cause analysis

Linear's hero is a WebGL/Three.js canvas rendered via GPU acceleration. Headless Chromium in `--no-sandbox` mode uses a software renderer that does not paint WebGL canvas contents — the canvas element is present in the DOM and the body text is fully hydrated (8225 chars), but the visual pixels stay black regardless of settle time. The fix is to detect this condition (near-empty frame + rich body text) and scroll below the hero to expose the regular HTML content that follows, which renders correctly.
